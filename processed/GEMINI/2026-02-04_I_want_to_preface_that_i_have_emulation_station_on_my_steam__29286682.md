# I want to preface that i have emulation station on my steam deck and each separate emulator on my cachyos desktop setup

### USER
I want to preface that i have emulation station on my steam deck and each separate emulator on my cachyos desktop setup

### GEMINI
That distinction matters because it introduces a structural mess. You have an organized frontend (EmulationStation-DE) on the Deck and a fragmented setup on CachyOS. If you don't map these paths perfectly, you’ll end up with duplicated data and broken symlinks. Here is the brutal reality: Syncing the saves is easy; syncing the ROMs is a bandwidth hog; and syncing the metadata (box art, play counts) between two different organizational structures is where most people fail and give up. 1. Mapping the Path Divergence EmulationStation (ES-DE) expects a specific folder hierarchy. Your standalone emulators on CachyOS likely point to default ~/.local/share or ~/Documents paths. To make this work, CachyOS must mimic the Steam Deck's structure. Do not try to make the Steam Deck adapt to your desktop; the Deck's OS is immutable and harder to move. Data TypeSteam Deck Path (Default)CachyOS Target PathSaves~/RetroArch/saves or ~/Emulation/saves/[SYSTEM]Match the Deck's structureStates~/RetroArch/states or ~/Emulation/states/[SYSTEM]Match the Deck's structureROMs~/Emulation/roms/[SYSTEM]~/Games/ROMs/[SYSTEM] 2. The Strategic Implementation Do not sync the entire Emulation folder. It’s too heavy. You need a three-tier sync strategy in Syncthing: Tier A: The "Brain" (Saves & States) This is non-negotiable. Create a folder in Syncthing called "RetroSaves". Map it to ~/Emulation/saves/ on the Deck. Map it to wherever your standalone emulators store saves on CachyOS. Warning: For standalone emulators (like PCSX2 or RPCS3) on CachyOS, you must go into their settings and manually redirect their save paths to this new synced folder. If you don't, you're just moving files into a void. Tier B: The "Body" (ROMs) The Opportunity Cost: Syncing 500GB of ROMs over Wi-Fi is a waste of disk health and electricity. The Move: Only sync the ROM folders for systems you are actively playing (e.g., GBA, 3DS). Set these folders to "Send & Receive." For massive libraries (PS3/Switch), keep them local or use a NAS. Tier C: The "Face" (ES-DE Metadata) Since you use ES-DE on the Deck, you likely want your scraped images and "Last Played" data to match. Sync ~/.emulationstation/gamelists and ~/.emulationstation/downloaded_media. The Risk: If the file paths for the ROMs aren't identical on CachyOS, ES-DE will show the art but won't launch the game. 3. The "Proton" Blind Spot Since you are on CachyOS (Arch-based), you are likely using the AUR. If you are using Flatpak versions of emulators on the Deck but Repo/AUR versions on CachyOS, the save locations are fundamentally different. Steam Deck (Flatpak): ~/.var/app/[com.emulator.Name]/data/... CachyOS (Native): ~/.config/[emulator]/... The Fix: Use Symlinks. Create a master folder: ~/Sync/EmulatorData. Move your actual save files there. Link them back: ln -s ~/Sync/EmulatorData/RetroArch/saves ~/.config/retroarch/saves. The Next Step Plan Consolidate: Pick one game today. Find its save file on CachyOS and its save file on the Deck. Standardize: Are you using the same "Core" or Emulator version? If CachyOS is running a cutting-edge nightly build and the Deck is on a stable Flatpak, the save file might become "forward-incompatible." Ensure versions match. Execute: Set up a Syncthing share specifically for that one game's save folder. Do you want the terminal commands to create the symlinks for your specific emulators so you don't accidentally delete your current progress while moving folders?
