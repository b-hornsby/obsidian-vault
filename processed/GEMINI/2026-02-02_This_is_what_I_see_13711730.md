When you edited the line, you likely hit Enter, which pushed the root=UUID... part onto a new line. In Limine, the cmdline must be one continuous string. Because that second line doesn't start with a valid command, the bootloader is essentially having a stroke. The Emergency Rescue Plan You must fix the syntax right now in that editor screen to get back into your OS: Join the lines: Use your arrow keys to go to the very beginning of the red text (where it says root=UUID...). Backpsace: Hit backspace until that text jumps back up to the end of the line above it (after rootflags=subvol=/@). Ensure a Space: Make sure there is exactly one space between subvol=/@ and root=UUID. Remove the Lax Flag: Since we know it's causing issues, delete acpi_enforce_resources=lax while you are there.
