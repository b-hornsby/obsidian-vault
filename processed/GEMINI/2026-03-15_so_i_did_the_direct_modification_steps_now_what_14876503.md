# so i did the direct modification steps. now what?

### USER
so i did the direct modification steps. now what?

### GEMINI
If you finished the Direct Modification (editing /boot/grub/grub.cfg and saving), you are ready for the moment of truth. 1. The Reboot Since you edited the file that the motherboard reads directly at startup, you don't need to run any "update" commands (running grub-mkconfig now would actually revert your changes). Close your terminal. Restart your computer. Check the "Select World" screen. 2. What to Look For The Main Title: Does it now say CachyOS instead of Arch Linux? The Windows Title: Does it say Tiny11 (or whatever you chose) without the long /dev/nvme... path? 3. "I want to change the under-text" If the titles look good but you hate the "Creative Mode" or the "Date" text underneath, here is the unfiltered truth: That text is being procedurally generated by the Minegrub theme logic. If you want to change that secondary line of text (the "Creative Mode, Cheats" part), we have to go deeper into the theme files. Navigate here: cd /boot/grub/themes/minegrub-world-selection/ Run ls and look for a file called theme.txt. Is the under-text exactly what you want it to be right now, or should we crack open that theme.txt to fix the descriptions?
