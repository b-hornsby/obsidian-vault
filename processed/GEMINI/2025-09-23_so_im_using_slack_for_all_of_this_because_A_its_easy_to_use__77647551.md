Step 2: Environment Setup It's best practice to create a virtual environment to manage your project's dependencies. # Create a new directory for your project mkdir llm_slack_bot cd llm_slack_bot # Create and activate a virtual environment python -m venv venv # On Windows venv\Scripts\activate # On macOS/Linux source venv/bin/activate Step 3: Install Core Libraries You will need a few key Python libraries to load and run the model in 4-bit precision. transformers: The core library from Hugging Face for loading the model. torch: The deep learning framework that transformers uses. accelerate: A library from Hugging Face to easily run models across multiple devices (e.g., CPU and GPU). bitsandbytes: This is the crucial library for 4-bit quantization. Flask or FastAPI: We'll use one of these to create a simple, local API endpoint for the LLM. pip install torch accelerate transformers bitsandbytes flask Step 4: Download and Load Mistral 7B Now you'll write a Python script to download the model from the Hugging Face Hub and load it in 4-bit mode. Create a file named llm_api.py. Paste the following code, which sets up the quantization configuration and loads the model. import torch from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig from flask import Flask, request, jsonify app = Flask(__name__) # --- Mistral 7B 4-bit setup --- model_id = "mistralai/Mistral-7B-Instruct-v0.2" bnb_config = BitsAndBytesConfig( load_in_4bit=True, bnb_4bit_use_double_quant=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.bfloat16 ) print("Loading tokenizer...") tokenizer = AutoTokenizer.from_pretrained(model_id) print("Loading model...") model = AutoModelForCausalLM.from_pretrained( model_id, quantization_config=bnb_config, device_map="auto", trust_remote_code=True ) print("Model loaded successfully!") # --- API Endpoint --- @app.route('/generate', methods=['POST']) def generate_text(): data = request.json prompt = data.get('prompt', '') if not prompt: return jsonify({'error': 'No prompt provided'}), 400 try: inputs = tokenizer(prompt, return_tensors="pt").to("cuda" if torch.cuda.is_available() else "cpu") # Adjusting generation parameters for a summary output_tokens = model.generate( **inputs, max_new_tokens=256, # Adjust based on your needs do_sample=True, temperature=0.7, top_k=50, top_p=0.95 ) response = tokenizer.decode(output_tokens[0], skip_special_tokens=True) # The model will return the full prompt + the new text. We need to extract just the new text. generated_text = response[len(prompt):].strip() return jsonify({'generated_text': generated_text}) except Exception as e: return jsonify({'error': str(e)}), 500 if __name__ == '__main__': # Running the server on a local port. You can change the port if needed. app.run(host='0.0.0.0', port=5000) Step 5: Run the LLM API Server From your terminal, with the virtual environment activated, run the script. python llm_api.py This will begin downloading the model (which may take a while) and then start a local web server on http://localhost:5000. You can test it with a tool like curl or a simple Python script. To test the API from a new terminal: curl -X POST -H "Content-Type: application/json" -d '{"prompt": "Summarize the key takeaways from a software development team's daily standup meeting."}' http://localhost:5000/generate If everything is set up correctly, you should get a response with a generated summary.
