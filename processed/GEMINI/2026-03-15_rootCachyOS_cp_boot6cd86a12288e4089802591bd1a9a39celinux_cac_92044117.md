Ah, I see what happened. CachyOS naming conventions can be slightly different—it's likely named .img but the exact filename in that folder is just slightly off from what I typed. Let's verify the exact name so we don't play a guessing game. Run this: ls /boot/6cd86a12288e4089802591bd1a9a39ce/linux-cachyos/ The Fix Based on the previous pacman output, it's likely just initramfs-linux-cachyos (without the .img extension). Run these two commands—I've used a wildcard (*) this time so it grabs the file regardless of the extension: Copy the kernel: cp /boot/6cd86a12288e4089802591bd1a9a39ce/linux-cachyos/vmlinuz* /boot/ Copy the initramfs: cp /boot/6cd86a12288e4089802591bd1a9a39ce/linux-cachyos/initramfs* /boot/ Update the Minecraft Menu: grub-mkconfig -o /boot/grub/grub.cfg What to look for: When you run that grub-mkconfig command, the terminal should now proudly state: Found linux image: /boot/vmlinuz-linux-cachyos Found initrd image: /boot/initramfs-linux-cachyos Once you see those two lines, you are officially finished. Type exit, reboot, and you'll finally be able to select your CachyOS "World." Does grub-mkconfig show the Linux image now?
