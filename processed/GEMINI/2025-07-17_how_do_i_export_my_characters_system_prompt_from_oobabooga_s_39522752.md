# how do i export my character's system prompt from oobabooga so i can use it within my workflow?

### USER
how do i export my character's system prompt from oobabooga so i can use it within my workflow?

### GEMINI
You're looking to extract the "essence" of your Oobabooga character to use as a system prompt in another workflow. Oobabooga stores character data in specific files, and understanding their structure is key. Oobabooga characters are typically saved in the text-generation-webui/characters directory. They can be in a few formats, but the most common for direct text extraction are JSON or YAML files, or embedded within PNG image files (TavernAI format). Here's how to export and identify your character's system prompt: 1. Locate Your Character File in Oobabooga Navigate to the characters directory: Go to your Oobabooga installation folder (e.g., text-generation-webui). Inside, you'll find a characters subfolder. This is where all your saved characters reside. Identify your character's file: Look for a file named after your character (e.g., MyCharacter.json, MyCharacter.yaml, or MyCharacter.png). 2. Extract the System Prompt (Context) The "system prompt" or "context" for a character in Oobabooga is usually found in a field that describes the character's personality, background, and instructions. This is often labeled as context, description, or persona. A. If your character is a .json or .yaml file: Open the file with a text editor: Use Notepad, VS Code, Sublime Text, or any code editor to open the .json or .yaml file. Look for the relevant fields: You'll typically find keys like: "context" "description" "persona" "system_prompt" (less common, but possible if custom) Sometimes, there might also be greeting or example_dialogue fields. While useful for the character, the core "system prompt" is usually the descriptive context/description/persona that defines who the character is. Example (JSON): { "name": "My Character", "description": "My Character is a helpful AI assistant designed to provide concise and accurate information. They maintain a polite and professional tone, and always strive to be unbiased. They avoid making personal opinions or engaging in casual conversation unless explicitly asked.", "greeting": "Hello! How can I assist you today?", "example_dialogue": "..." } In this example, the content of "description" would be your system prompt. B. If your character is a .png (TavernAI character card): TavernAI character cards embed the character data within the PNG image file as metadata. You can't just open them with a text editor. Use Oobabooga's UI to view/export: Load the character in Oobabooga's "Character" tab. While Oobabooga doesn't have a direct "export text" button, when you load a character card, the fields (like "Context," "Greeting," "Persona") become populated in the UI. You can then manually copy the text from the "Context" or "Description" text area. Use an online character card editor (recommended): Websites like https://oobabooga.github.io/character-creator.html or https://chub.ai/ (if you upload it there, then download as JSON) can parse these PNGs and show you the underlying JSON/text data, allowing you to easily copy the context or description field. 3. Integrate into Your Workflow Once you have the raw text of your character's system prompt, you can integrate it into your CrewAI workflow. You would typically use this as the system message in your messages list when making API calls, or as part of the backstory or goal for an agent in CrewAI, depending on how detailed and structured you want your agent's persona to be. Example for CrewAI Agent backstory (most common use): from crewai import Agent, Task, Crew, Process import os # ... (your Oobabooga API configuration from previous step) ... os.environ["OPENAI_API_BASE"] = "http://localhost:5000/v1" os.environ["OPENAI_API_KEY"] = "sk-not-needed-for-local" os.environ["OPENAI_MODEL_NAME"] = "gpt-3.5-turbo" # Your extracted system prompt/context from Oobabooga character_system_prompt = """ My Character is a helpful AI assistant designed to provide concise and accurate information. They maintain a polite and professional tone, and always strive to be unbiased. They avoid making personal opinions or engaging in casual conversation unless explicitly asked. """ # Define your CrewAI Agent using the extracted prompt my_agent = Agent( role='Information Provider', goal='Deliver factual and unbiased answers to user queries.', backstory=character_system_prompt, # Use the extracted system prompt here verbose=True, allow_delegation=False ) # ... (rest of your CrewAI workflow) ... This approach allows you to maintain the core personality and instructions you've crafted in Oobabooga within your external multi-agent system.
