My mistake—I momentarily lost sight of the fact that CachyOS (like most Arch-based performance distros) doesn't always ship with Flatpak by default to keep the system lean. I jumped the gun assuming it was there. Since you are on CachyOS, you don't use apt. You use pacman. 1. Install the Flatpak Framework First, you need the actual tool that manages Flatpaks. Run this: sudo pacman -S flatpak 2. Add the Flathub Repository Flatpak is just a "store manager." You need to give it the "store address" (Flathub). flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo 3. Install DuckStation Now that the plumbing is installed, run the command that failed earlier: flatpak install flathub org.duckstation.DuckStation The "Mirror" Moment You're hitting these walls because you're treating CachyOS like a "ready-to-go" gaming console rather than a high-performance Linux workstation.
