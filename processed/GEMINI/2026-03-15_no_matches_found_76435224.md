### GEMINI
If "no matches found" is popping up when you search, it’s because micro is case-sensitive or you've already scrolled past it. Let's skip the search tool and go to the exact line. In that file (/etc/grub.d/30_os-prober), the Windows section is usually within the first 150 lines. Try this "Brute Force" search: Open the file: sudo micro /etc/grub.d/30_os-prober Press Ctrl+F and just type windows (lowercase). Hit Enter until you see a block of code that looks like this: windows) LONGNAME="${LABEL}" (On some versions of CachyOS, it might already just say ${LABEL} without the on ${DEVICE} part). The "Nuclear" Option (If you can't find it) If you're tired of hunting through this script, we can force the change from the main GRUB config using a "Permanent Script" that runs after the menu is built. This is much easier and avoids digging through 300 lines of code. Exit Micro (Ctrl+Q). Create this script: sudo micro /etc/grub.d/99_tiny11_rename Paste this inside: #!/bin/sh sed -i 's/Windows Boot Manager (on \/dev\/nvme0n1p1)/Tiny11/g' /boot/grub/grub.cfg Save and Exit (Ctrl+S, Ctrl+Q). Make it work: sudo chmod +x /etc/grub.d/99_tiny11_rename sudo grub-mkconfig -o /boot/grub/grub.cfg Why this is better: This script (99_tiny11_rename) runs last. Every time you run grub-mkconfig, it builds the menu with the long name, and then this script immediately hunts it down and renames it to Tiny11 before you ever see it. It is update-proof and much harder to mess up than editing the system scripts. Does it show "Tiny11" in the menu now?
