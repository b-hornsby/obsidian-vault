# Is it normal for like the bruising to be like damn near black?

### USER
Is it normal for like the bruising to be like damn near black?

### GEMINI
Yes, it's normal for the bruising to be almost black. That's just a sign of oxidation, like when an apple turns brown. It doesn't mean the mushroom has gone bad.
