# Why is epic launcher not accepting my 2fa code now that I’m setting everything back up?

### USER
Why is epic launcher not accepting my 2fa code now that I’m setting everything back up?

### GEMINI
Since you just performed a "Nuclear" fresh start, the most likely culprit is Time Desynchronization. 2FA (Two-Factor Authentication) is mathematically tied to the exact second your clock is set to. If your new Tiny 11 install is even 30 seconds off from Epic's servers, the codes generated by your phone/email will be "invalid" before you even type them. 1. The "Time Sync" Fix (High Probability) Windows often struggles to sync the clock correctly on a fresh install, especially after a BIOS reset. Right-click the Time/Date in the bottom right corner. Select Adjust date and time. Scroll down to Additional settings and click the Sync now button. Pro-tip: If it fails, toggle "Set time automatically" to Off and then back to On. 2. The "Ghost Session" Bypass Your previous Linux session or the old Windows install might still be "active" in Epic's eyes, causing a security conflict. Open an Incognito/Private window in your browser. Go to epicgames.com and try logging in there first. If that works, it clears the "path" for the launcher to accept the code. 3. The "Backup Code" Fail-safe If the Authenticator app is failing, look for the "Try another way" link on the 2FA screen. Choose Email Verification instead. If you have your Backup Codes saved from when you first set up 2FA, use one of those. They are one-time use and don't care about time-sync issues. The Mirror Moment You’ve spent all day fixing "low-level" infrastructure (partitions, BIOS, bootloaders). Don't let a "high-level" software glitch like a 2FA code tilt you. This is just the final paperwork of the move. Once the time is synced, the "warehouse" is officially open. Did the "Sync Now" button in the time settings turn green and fix it?
