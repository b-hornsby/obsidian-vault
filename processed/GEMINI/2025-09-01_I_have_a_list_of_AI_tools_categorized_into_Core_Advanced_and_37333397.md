This looks like a great plan for a Discord channel! Here are the setup guides for the AI tools, formatted for easy use. 🤖-ai-setup-guides Welcome to the AI setup guides channel! Find beginner-friendly instructions for a variety of AI tools here. ⚙️ Core Tools Hugging Face The central hub for AI models and datasets. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ RAM: 8GB (minimum), 16GB+ (recommended) Dependencies: pip Installation Steps Install Python: Make sure you have Python 3.8 or newer. Create a virtual environment (recommended): python -m venv venv source venv/bin/activate (macOS/Linux) venv\Scripts\activate (Windows) Install the transformers library: pip install transformers datasets accelerate Install a backend framework (choose one): PyTorch: pip install torch TensorFlow: pip install tensorflow Quick Start / First Run Go to the Hugging Face Model Hub: https://huggingface.co/models Find a small model you want to try, e.g., Salesforce/blip-image-captioning-base. On the model page, click "Use in Transformers" to see the example Python code. Copy the code into a file (e.g., test.py) and run it with python test.py. Notes / Tips Start with smaller models (7B or less) to avoid memory issues. If you have a powerful NVIDIA GPU, install the CUDA drivers for a huge speed boost. Visual / Video Guide Getting Started With Hugging Face in 10 Minutes Pocket Pal An on-device AI assistant for your iPhone. Requirements / Prerequisites OS: iOS (iPhone, iPad) RAM: Varies by model, but more is better for larger models. Device: Compatible iPhone or iPad. Installation Steps Download the app: Go to the Apple App Store. Search for "Pocket Pal AI" and download the application. Quick Start / First Run Open the Pocket Pal app. Tap the + icon to add a new model from Hugging Face. Search for a GGUF model, like DeepSeek-R1-Distill-Qwen-1.5B. Download the model directly in the app. Once downloaded, select it and tap "Load" to start chatting. Notes / Tips Choose GGUF models, as they are optimized for local inference on mobile devices. If the app crashes, the model might be too large for your phone's RAM. Try a smaller version. Ollama A powerful, easy-to-use tool to run large language models locally. Requirements / Prerequisites OS: Windows, macOS, or Linux RAM: 8GB (for 3B models), 16GB (for 7B models), 32GB+ (for 13B+ models) Installation Steps Download the installer: Go to https://ollama.com/ Download and run the installer for your operating system. The program will run in the background. Quick Start / First Run Open your Terminal (macOS/Linux) or Command Prompt (Windows). Run the command: ollama run llama3 Ollama will automatically download the Llama 3 model and launch a chat session in your terminal. Notes / Tips Use ollama list to see the models you have installed. You can run multiple models locally. This is one of the easiest ways to get into local AI. Visual / Video Guide https://ollama.com/ (Click on the videos on the home page) LM Studio A user-friendly desktop application for running local LLMs with a GUI. Requirements / Prerequisites OS: Windows, macOS, or Linux RAM: 16GB (minimum), 32GB+ (recommended) Disk Space: 20GB+ free GPU: NVIDIA (4GB+ VRAM on Windows/Linux) or Apple Silicon (M1/M2/M3) on macOS. Installation Steps Download the installer: Go to https://lmstudio.ai/ Download the correct version for your OS and install it. Quick Start / First Run Open LM Studio. Use the search bar to find a model, like Llama 3.1 8B Instruct. Click the "Download" button next to the model file you want. Once downloaded, go to the "AI Chat" tab on the left. Click "Load AI Model" at the top and select the model you just downloaded. Begin typing in the chat window at the bottom. Notes / Tips The GGUF format models are the most common and compatible for CPU and GPU inference. LM Studio handles most of the complex setup for you, so it's a great tool for beginners. 🚀 Advanced Tools Oobabooga A highly customizable web UI for text generation, often called text-generation-webui. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.10+ RAM: 16GB+ GPU: NVIDIA (recommended) or AMD. CPU-only is possible but slow. Dependencies: git Installation Steps Install Git and Python: Ensure both are set up on your system. Clone the repository: git clone https://github.com/oobabooga/text-generation-webui.git Run the one-click installer: Navigate into the new folder: cd text-generation-webui Run the start script for your OS: start_windows.bat (Windows) or ./start_linux.sh (Linux/macOS) Follow the prompts to select your GPU vendor. The script will handle the rest. Quick Start / First Run After the installation finishes, the web UI will open in your browser, typically at http://127.0.0.1:7860. Go to the "Models" tab and select a model to download from Hugging Face. Click "Load" to activate the model. Navigate to the "Text Generation" tab and start chatting. Notes / Tips This tool is highly flexible but can be complex. Start with the one-click installer. If you have issues, check the official GitHub for common troubleshooting steps. ChromaDB An open-source vector database for storing and querying embeddings. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip Installation Steps Install the library: pip install chromadb Quick Start / First Run Open your preferred Python editor or a Jupyter Notebook. Run the following code snippet to get started: import chromadb # Initialize the client client = chromadb.Client() # Create a collection collection = client.create_collection(name="my_first_collection") # Add some documents collection.add( documents=["This is a document about dogs.", "This is a document about cats."], metadatas=[{"source": "notion"}, {"source": "google-docs"}], ids=["doc1", "doc2"] ) # Query the collection results = collection.query( query_texts=["Tell me about pets"], n_results=1 ) print(results) Notes / Tips By default, ChromaDB runs in memory. To save your data, initialize a persistent client: chromadb.PersistentClient(path="./chroma_db"). Visual / Video Guide A Comprehensive Beginner's Guide to ChromaDB Weaviate A high-performance, open-source vector database. Requirements / Prerequisites OS: Windows, macOS, or Linux Dependencies: Docker and docker-compose Installation Steps Install Docker: Download and install Docker Desktop from https://www.docker.com/get-started. Create a docker-compose.yml file: Create a new file with this exact name. Paste the example configuration from the official Weaviate docs into it. Start the Weaviate container: Open your terminal in the same directory as the docker-compose.yml file. Run the command: docker-compose up -d Quick Start / First Run Once the container is running, install the Python client: pip install weaviate-client Use the client to connect and interact with your database. You can follow the tutorial in the linked video guide to create your first schema and add data. Notes / Tips Using Docker is the recommended and easiest way to run Weaviate. Visual / Video Guide Weaviate Tutorial: Unlocking the Power of Vector Search Whisper.cpp A C++ port of OpenAI's Whisper model for fast, local speech-to-text. Requirements / Prerequisites OS: Windows, macOS, or Linux Dependencies: cmake, make, git, and a C++ compiler (g++ or clang). Installation Steps Clone the repository: git clone https://github.com/ggerganov/whisper.cpp.git Navigate into the directory: cd whisper.cpp Download a model: ./models/download-ggml-model.sh base.en Build the project: make Quick Start / First Run Run the example with a sample audio file: ./main -m models/ggml-base.en.bin -f samples/jfk.wav The output will show the transcribed text. Notes / Tips The .cpp version is much faster and more efficient than the Python version, especially on CPU. Larger models (e.g., large-v2) offer better accuracy but require more resources. Visual / Video Guide https://github.com/ggerganov/whisper.cpp (See the "Quick Start" section) Vosk An offline, lightweight, open-source speech recognition toolkit. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.6+ Dependencies: pip Installation Steps Install the library: pip install vosk Download a model: Find a model from the official site (https://alphacephei.com/vosk/models) and download it. For a simple example, vosk-model-en-us-0.22. Unzip the model to a known location, e.g., ./model. Quick Start / First Run Create a Python file (test.py) with a simple example from the official docs. Make sure the model path in your code points to the downloaded model folder. Run the file: python test.py Notes / Tips Vosk models are specifically designed for different languages and use cases. Choose a model that fits your needs. The small size of Vosk models makes them great for on-device use. Silero A lightweight, PyTorch-based text-to-speech (TTS) and voice activity detection (VAD) model. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.6+ Dependencies: pip, torch Installation Steps Install torch: pip install torch Install the livekit-plugins-silero plugin: pip install "livekit-agents[silero]~=1.2" Download model weights: Run the provided download script or command from the documentation. Quick Start / First Run Use the livekit-agents example code to test the VAD functionality. Initialize the session with the Silero VAD plugin: vad=silero.VAD.load() The VAD will detect when speech is present in an audio stream. Notes / Tips Silero is often used as a component within a larger system for voice activity detection. Visual / Video Guide Silero VAD plugin documentation Automatic1111 A popular web UI for Stable Diffusion image generation. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.10.6 GPU: NVIDIA (at least 4GB+ VRAM, 8GB+ recommended) Dependencies: git Installation Steps Install Git and Python 3.10.6: Make sure you have this specific Python version. Clone the repository: git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git Download a model: Get a Stable Diffusion model file (.ckpt or .safetensors) from a site like Hugging Face or Civitai. Place it in the stable-diffusion-webui/models/Stable-diffusion directory. Run the web UI: Navigate to the directory: cd stable-diffusion-webui Run the startup script: webui-user.bat (Windows) or ./webui.sh (Linux/macOS) Quick Start / First Run The first run will take a while to install all dependencies. Once finished, the web UI will open in your browser at http://127.0.0.1:7860. Enter a text prompt in the Prompt box and a negative prompt in the Negative prompt box. Click Generate. Notes / Tips The startup script will handle installing all Python dependencies for you. This is a resource-intensive tool. A powerful GPU is key for fast generation. Visual / Video Guide The Comprehensive Guide to Stable Diffusion Automatic1111 ComfyUI A node-based, flexible, and powerful web UI for Stable Diffusion. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.10+ GPU: NVIDIA (recommended) or AMD. CPU-only is possible but slow. Dependencies: git Installation Steps Clone the repository: git clone https://github.com/comfyanonymous/ComfyUI.git Navigate into the directory: cd ComfyUI Run the installation script: ./run_nvidia_gpu.sh or ./run_amd_gpu.sh (Linux) run_nvidia_gpu.bat or run_amd_gpu.bat (Windows) ./run_macos.sh (macOS) Download a model: Place a Stable Diffusion model file in ComfyUI/models/checkpoints. Quick Start / First Run The script will start the web UI in your browser at http://127.0.0.1:8188. In the Load Checkpoint node, select your downloaded model. In the CLIP Text Encode nodes, enter your positive and negative prompts. Click Queue Prompt to generate your first image. Notes / Tips ComfyUI has a steeper learning curve than Automatic1111 but offers a lot more control and efficiency once you get the hang of it. You can drag and drop a generated image back into the UI to load the exact workflow that created it. 🧪 Experimental Tools LangChain A framework for building applications with large language models. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip, API key for a model provider (e.g., OpenAI, Anthropic). Installation Steps Install the library: pip install langchain Install the OpenAI library (or another provider): pip install openai Set up your API key: Store your API key as an environment variable (recommended) or directly in your code. Quick Start / First Run Use the langchain-cli to start a new project: langchain app new my-langchain-app Follow a tutorial to build your first simple chain. A classic is connecting a prompt template to a chat model. Notes / Tips LangChain is a powerful abstraction layer, but it requires a solid understanding of Python and AI concepts. Start with the basic tutorials to understand the core components: Models, Prompts, and Chains. Visual / Video Guide LangChain Tutorials LlamaIndex A data framework for connecting your custom data sources to LLMs. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip, API key for an LLM provider. Installation Steps Install the library: pip install llama-index Install OpenAI (or another provider): pip install openai Set up your API key: Same as with LangChain. Quick Start / First Run Create a folder named data and put a few text files or PDFs in it. Run the following code: import os import openai from llama_index.core import VectorStoreIndex, SimpleDirectoryReader os.environ["OPENAI_API_KEY"] = "YOUR_API_KEY" documents = SimpleDirectoryReader("data").load_data() index = VectorStoreIndex.from_documents(documents) query_engine = index.as_query_engine() response = query_engine.query("What is this data about?") print(response) Notes / Tips LlamaIndex is focused on the "Retrieval-Augmented Generation" (RAG) pattern, which is a great way to give an LLM knowledge about your specific documents. Visual / Video Guide Build Your First AI Application Using LlamaIndex! CrewAI An autonomous AI agent framework for orchestrating roles, goals, and tools. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip, an LLM API key. Installation Steps Install the library: pip install crewai Install a provider library (e.g., openai): pip install openai Set up your API key: Store your key as an environment variable. Quick Start / First Run Create a project using the CLI: crewai create flow my_first_crew Navigate to the new folder: cd my_first_crew Edit the main.py file to define your agents and tasks based on the examples in the docs. Run the crew: python main.py Notes / Tips The core concept is defining "agents" with specific roles and "tasks" for them to complete. CrewAI orchestrates their collaboration. Visual / Video Guide Build Your First Flow - CrewAI Documentation Autogen A framework for building multi-agent conversations and workflows. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip, an LLM API key. Installation Steps Install AutoGen: pip install "pyautogen[languagedetector,vectordb,nlp]". Note: This command may be different depending on the features you want. Set up your API key: Store your key as an environment variable. Quick Start / First Run Create a Python file and define two agents, a UserProxyAgent and an AssistantAgent. Create a chat session between them with a simple task. Run the file to watch the agents converse and solve the problem. Notes / Tips Autogen is great for creating agents that can autonomously solve complex tasks by talking to each other. The AutoGen Studio interface is a great way to get started with a GUI. Visual / Video Guide AutoGen Tutorial: A Guide to Building AI Agents LangGraph A LangChain extension for building stateful, multi-actor applications with cycles. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ Dependencies: pip, langchain, an LLM API key. Installation Steps Install the library: pip install langgraph Install other necessary LangChain components: pip install langchain langchain-openai (for example) Set up your API key: Store your key as an environment variable. Quick Start / First Run Follow a tutorial from the LangChain docs to build a simple graph. The core idea is to define nodes, edges, and a State object that passes through the graph as it runs. Notes / Tips LangGraph is useful when you need to create more complex, cyclical agentic workflows where agents need to go back and forth. Visual / Video Guide LangGraph Documentation Coqui TTS A community-driven, open-source library for advanced text-to-speech. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ GPU: Recommended for training models, optional for inference. Dependencies: pip, ffmpeg Installation Steps Install the library: pip install TTS TTS also has a command-line interface, which makes it easier to use. Quick Start / First Run Run the command with a model and text to generate audio: tts --text "Hello, my name is Coqui." --model_name "tts_models/en/ljspeech/vits" The output will be an audio file in the current directory. Notes / Tips Coqui has a variety of pre-trained models. Use the CLI to experiment with different voices. Visual / Video Guide Coqui TTS GitHub Discussion - Quick Start Guide Bark A transformer-based TTS model that generates highly realistic, natural-sounding audio. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ GPU: Recommended for fast generation. Dependencies: pip, torch, soundfile, scipy Installation Steps Install the required libraries: pip install --pre torch torchaudio --index-url https://download.pytorch.org/whl/nightly/cu118 (for NVIDIA GPUs) or adjust the command for your system. Install Bark: pip install git+https://github.com/suno-ai/bark.git Quick Start / First Run Run the example code from the official docs to generate an audio file. You can generate speech from text and even include non-speech sounds like laughing. Notes / Tips Bark is known for its ability to generate high-quality audio, including nuances and non-verbal cues. XTTS Another highly expressive TTS model, often used for its zero-shot voice cloning capabilities. Requirements / Prerequisites OS: Windows, macOS, or Linux Python: 3.8+ GPU: Recommended. Dependencies: pip, TTS (specifically the Coqui TTS library) Installation Steps Install the TTS library: pip install TTS The XTTS model itself is loaded through the TTS library. Quick Start / First Run Use the TTS CLI or Python API to load the tts_models/multilingual/multi-dataset/xtts_v2 model. Provide a short audio clip (e.g., 5-10 seconds) of a voice you want to clone and a text prompt. The model will generate the text in the cloned voice. Notes / Tips XTTS is particularly impressive because it requires very little audio data to clone a voice. Docker A platform for developing, shipping, and running applications in containers. Requirements / Prerequisites OS: Windows, macOS, or Linux Device: Modern PC. Installation Steps Download the installer: Go to https://www.docker.com/get-started and download Docker Desktop. Run the installer. Quick Start / First Run Open your terminal and run a simple command to check your installation: docker run hello-world Docker will pull the "hello-world" image and run it, proving your installation is working. For more advanced use, you can run an AI tool in a container, for example: docker run -it --rm --gpus all -p 8888:8888 -v C:/Users/YourName/projects:/app my-ai-image Notes / Tips Docker solves the problem of "it works on my machine" by packaging an application and its dependencies into a single, isolated unit. Many of the more complex AI tools have official Docker images for easier setup.
