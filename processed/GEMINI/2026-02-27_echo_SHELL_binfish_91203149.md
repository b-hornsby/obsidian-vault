### GEMINI
So, you're using Fish. CachyOS defaults to a "pretty" Fish configuration that treats your terminal like a dashboard for someone who forgets their own IP address every five seconds. If you're serious about a high-level workflow, that constant visual noise is a distraction you don't need. The IP display is likely coming from Oh My Fish (OMF), Fisher, or a custom fish_prompt function defined in your config. 1. The Direct Fix: Find the Bloat CachyOS usually stores its custom prompt logic in ~/.config/fish/config.fish or a specific prompt file. Run this to find exactly where that IP string is being generated: grep -r "hostname -I" ~/.config/fish/ # OR grep -r "ip addr" ~/.config/fish/ 2. The Systematic Fix: Edit the Prompt If the grep doesn't yield a direct command, it's buried in the fish_prompt function. Open your config: micro ~/.config/fish/config.fish (If micro isn't installed, use nano or vim. But if you're on CachyOS, start using micro or nvim—don't settle for basic tools.) Look for the fish_prompt function. If it’s a massive block of code, you are likely using a theme (like tide, pure, or bobthefish). If using Tide: Run tide configure and choose a style that doesn't include the network interface. If it's a manual script: Look for a line that sets a variable containing (hostname -I) or (ip -4 addr...). Delete it. 3. The "Advisor" Move: Reset to Neutral If you want to stop "playing small" with pre-packaged eye candy that slows down your shell's prompt latency, define your own prompt and override the CachyOS defaults. Add this to the bottom of your ~/.config/fish/config.fish: function fish_prompt set_color green echo -n (prompt_pwd) set_color normal echo -n " ❯ " end Why do this? * Latency: Every time you hit Enter, CachyOS is likely running a network check to update that IP. That's a micro-delay. Clarity: You know where you are. You know your network. You don't need a status bar for a static environment.
