# i want this to stick

### USER
i want this to stick

### GEMINI
To make this stick permanently so you never have to think about it again—even after updates—we have to stop trying to edit the file while it's being made. Instead, we’ll use a "Post-Generation Hook." Since you're on CachyOS (Arch), the most bulletproof way to do this is to create a Pacman Hook. This tells your system: "Every time you update the system or the bootloader, run my rename command automatically." 1. Create the Hook Directory First, make sure the folder exists: sudo mkdir -p /etc/pacman.d/hooks 2. Create the "Sticky" Hook Create a new file: sudo micro /etc/pacman.d/hooks/grub-rename.hook 3. Paste this configuration This is the "logic" that ensures it never reverts: [Trigger] Type = Package Operation = Install Operation = Upgrade Target = grub Target = cachyos-settings [Trigger] Type = Path Operation = Install Operation = Upgrade Operation = Remove Target = boot/grub/grub.cfg [Action] Description = Ensuring Tiny11 name sticks in GRUB... When = PostTransaction Exec = /usr/bin/sed -i "s/menuentry 'Windows Boot Manager (on \/dev\/nvme0n1p1)'/menuentry 'Tiny11'/g" /boot/grub/grub.cfg 4. Save and Exit Press Ctrl+S, then Ctrl+Q. Why this works: Trigger: It watches the grub.cfg file. If anything (an update, a kernel change, or you running the command) touches that file, the trigger trips. Action: Immediately after the change is finished, it runs your successful sed command to swap "Windows Boot Manager" for "Tiny11." The "I'm Done" Test To prove this works forever, run your grub update command one last time: sudo grub-mkconfig -o /boot/grub/grub.cfg Then check the name: sudo grep "menuentry 'Tiny11'" /boot/grub/grub.cfg If you see menuentry 'Tiny11', you've officially beaten the system. Ready to reboot and enjoy the clean menu?
