The image confirms you are stuck on the SteamOS "Launching" transition. This is the "handshake" phase where Steam is waiting for the Citron AppImage to tell the screen it's ready to display. Because you wiped your folders and installed a new update, Citron is working overtime behind that screen. Here is why it's taking "mad long" and exactly what you need to do. 1. The "Gamescope" Handshake (The Real Bottleneck) In Game Mode, SteamOS won't show the emulator until the emulator reaches the first frame of the game. The Problem: TotK is currently rebuilding its internal cache and checking the NAND update you just installed. The Reality: On a Steam Deck, this specific "first boot" after an update can take 3 to 7 minutes. ### 2. The Final Troubleshooting Steps If you have been waiting more than 5 minutes, the emulator is likely waiting for a "Yes" or "OK" prompt that you can't see because it's hidden behind the Steam "Launching" logo. Do this sequence immediately: Hold the Steam Button + Right Trackpad: This acts as a mouse. Move it around. If you see a mouse cursor, the emulator is active but hasn't "taken over" the screen yet. Toggle the Performance Settings: Press the (…) button. Set Frame Limit to OFF. Set Refresh Rate to 60. If these are set to 30 or 45, the "Launching..." screen can literally hang forever because the emulator's refresh rate doesn't match Steam's compositor. The "Emergency Swap": If it still won't move, hold the Steam Button and press Left on the D-pad. This is the shortcut to "Switch Window." Sometimes the emulator opens a "Shader Compilation" window that Steam treats as a background task. Switching windows can force the game to the front. 3. The "Desktop-to-Game" Trick If you can't get it to move in Game Mode, there is one final way to force it to "save" its state so Game Mode works: Go back to Desktop Mode. Launch the game in Citron. Play for exactly one minute—walk around Link's house, open a menu, save the game. Close the game properly (File -> Exit). Now switch back to Game Mode. * Because the "First Run" data is now written to the disk, Game Mode should skip the heavy lifting and boot in under 30 seconds.
