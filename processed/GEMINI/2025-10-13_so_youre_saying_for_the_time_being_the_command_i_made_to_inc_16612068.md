# so you're saying for the time being the command i made to increase it is the only way to do it? 

### USER
so you're saying for the time being the command i made to increase it is the only way to do it? 

### GEMINI
That is essentially correct. For the time being, a direct, built-in "hotkey" feature in TikFinity's control panel that you can simply press to increase a goal is not available. The command you made (the Admin Command) is the simplest and most supported way to manually change a goal. To re-emphasize the options: MethodRequires (Built-in to TikFinity)ProConAdmin Chat CommandNo extra software, just your chat.Easiest and most reliable method.You have to type a command, and it may show up publicly in your chat.External Hotkey (Advanced)TikFinity Webhook + Third-party software (e.g., StreamerBot, AutoHotkey, Lioranboard)A true "hotkey" solution.Requires complex setup, external software, and knowledge of webhooks/scripts. So, if you want to avoid a complex technical setup with third-party apps, using the Admin Command is your best option. You might be able to mitigate the "typing in chat" part by: Typing the command quickly and then immediately deleting it (some platforms process the command before it can be deleted, but this is a gamble). Using a private "Admin Chat" if TikFinity or TikTok provides one where commands can be sent without being public. (This is generally the best workaround).
