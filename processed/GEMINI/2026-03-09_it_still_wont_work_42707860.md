Since we’ve hit a wall with obs-cmd authentication and your CachyOS firewall, we're going to pivot to the Wayland-native method. This is actually the "cleanest" way to do it in 2026 because it doesn't rely on background terminal commands or local network ports. We’re going to use the Wayland Global Shortcuts Portal. This lets the Operating System (KDE Plasma) talk to OBS directly without needing a password or a middleman. 1. Install the Native Plugin Since you already have paru, run this to get the bridge that connects OBS to your system shortcuts: paru -S obs-wayland-hotkeys-git 2. The Handshake (Important) Close OBS completely. Open OBS back up. A system window titled "Add Keyboard Shortcuts" should pop up automatically. This is KDE asking for permission to handle hotkeys for OBS. If it doesn't pop up, look at your taskbar for a notification icon or go to System Settings → Shortcuts → Global Shortcuts. 3. Map the Keys in the System (Not OBS) Once the plugin is installed, ignore the Hotkeys menu inside OBS. It's useless to you now. Open System Settings. Go to Keyboard → Shortcuts. On the left sidebar, you should now see OBS Studio (or just "OBS") as a category. Find "Save Replay" (or "Toggle Replay Buffer") in that list. Click it and assign your hotkey. Why this is the "Brutal Advisor" choice: You've spent the last 30 minutes fighting obs-cmd syntax and network sockets. That’s opportunity cost you can’t get back. This method: Eliminates the Password: No more "Authentication Failed" because the OS and OBS share a secure "portal" instead of a network socket. Bypasses the Firewall: It doesn't use a port, so ufw can't block it. Zero Stutter: It keeps OBS in Native Wayland mode, which is critical for your Apex and Fortnite performance. One Last Check for your "Vibe Coding" Workflow: If you still don't see "OBS" in your System Settings after installing that plugin and restarting, run this command to make sure the plugin is actually in the right folder: ls /usr/lib/obs-plugins/ | grep wayland Once you assign the key in System Settings, go test it in a game.
