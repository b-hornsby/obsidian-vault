That error message—"Make sure the format isn't empty and the path is valid"—is Tuna's way of saying it has a blank "Song info output" entry. You're seeing this because you likely clicked "Add new" but didn't actually fill in the details for that specific row before hitting OK. Here is exactly how to fix that error and get the text changing: 1. Fix the "Output Error" In Tuna settings, look at the Song info outputs box. If you see a blank row or the error keeps popping up, click Add new (or select the broken row and click Edit selected). Song format: Enter {title} - {artists}. Note: Avoid old placeholders like %t or %a, as newer versions of Tuna use the curly bracket system {}. Song info path: Click the ... button and select (or create) a file named nowplaying.txt in a safe location, like /home/toastedmel0n/nowplaying.txt. Click OK on that sub-window, then hit Start at the bottom of the main Tuna settings. 2. Verify MPRIS is "Talking" Since you are on CachyOS and want universal support (SoundCloud, YouTube, etc.), double-check your Basics tab one more time: Song source: Change this from "Spotify" to MPRIS. Song placeholder: If this still says "No song playing" even while music is active, go to the MPRIS tab and ensure your browser or player is checked in the list. 3. Displaying the Album Art You mentioned wanting the art with the text. Since your settings show the cover is being saved to /home/toastedmel0n/cover.png, do this in OBS: Add an Image Source: Point it to /home/toastedmel0n/cover.png. Add a Text Source: Check "Read from file" and point it to the /home/toastedmel0n/nowplaying.txt you just configured. The "6K Labs" Layout: Place the text source next to the image source in your OBS preview. Why the text wasn't changing: If the file path was set to a location requiring Admin rights or a directory that didn't exist, Tuna couldn't write the new data. Using a path directly in your /home/toastedmel0n/ folder solves this permission issue. Does the "Song placeholder" in the Tuna menu now show your actual song title instead of "No song playing"?
