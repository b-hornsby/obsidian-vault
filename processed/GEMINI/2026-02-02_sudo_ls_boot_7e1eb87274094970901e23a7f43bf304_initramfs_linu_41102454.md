### GEMINI
You are using Limine. It’s the modern, lightweight bootloader CachyOS has been pushing recently. Since you see limine.conf in that list, we need to edit the configuration to include the acpi_enforce_resources=lax parameter. This will clear that motherboard warning in OpenRGB. 1. The Limine Fix Run this command to open the configuration file: sudo nano /boot/limine.conf Inside the file, look for the line starting with cmdline:. It will likely look something like this: cmdline: root=UUID=... rw quiet splash The Action: Add a space at the end of that line (inside any quotes if they exist) and type: acpi_enforce_resources=lax Save and Exit: Press Ctrl+O, Enter, then Ctrl+X. Note: Unlike GRUB, Limine usually reads the config file directly on boot, so you don't need a "mkconfig" command. Just reboot. 2. The Fan Setup (The Actual Goal) While you're waiting to reboot, let's solve the fan issue. You still haven't told me your fan model, so here is the "Brutally Honest" manual for the Resize the Zones window you saw earlier: If you have a Lighting Node Core (which showed up in your screenshot), you need to tell it how many LEDs to drive. If you enter 0, the fans stay off. The Reality Check You are chasing the "Motherboard Warning" because it's an error message, but the Fans are what you actually care about. Even without the lax fix, your fans will work if you just put the right number in that Size box. The Blind Spot: You are doing a lot of configuration for a system you're still learning.
