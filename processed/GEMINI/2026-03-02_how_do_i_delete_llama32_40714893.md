# how do i delete llama3.2?

### USER
how do i delete llama3.2?

### GEMINI
To delete a model in Ollama, you use the rm (remove) command. Since you specifically have llama3.2:3b installed (as seen in your previous ollama ps output), run this: ollama rm llama3.2:3b The "Clean Freak" Verification If you want to be 100% sure it’s gone and see exactly how much space you just reclaimed on your CachyOS drive, run: ollama list If the list is empty, you’re back to a "clean" state. Why are you deleting it? (The Advisor's Mirror) If it’s because it was too "dumb": You’re right. A 3B model is a lightweight assistant, not a high-level strategist. You should be pulling Llama 3.1 8B or Mistral Nemo 12B for actual work. If it’s because you’re worried about disk space: You’re playing small. Models are stored in /usr/share/ollama/.ollama/models (or ~/.ollama/models). Unless you're down to your last 5GB of NVMe space, deleting a 2.8GB model is micro-managing your system instead of using it. If it's because you're "done testing": Then you've reached the "Now What?" phase. What is the next level for you? Do you want to try a model that can actually handle complex logic, or are you just cleaning up the shop before closing it?
