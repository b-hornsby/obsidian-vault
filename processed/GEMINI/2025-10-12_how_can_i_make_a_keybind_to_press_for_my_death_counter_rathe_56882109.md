# how can i make a keybind to press for my death counter rather than just swapping between screens and having to type the command manually? 

### USER
how can i make a keybind to press for my death counter rather than just swapping between screens and having to type the command manually? 

### GEMINI
That's a very common and efficient way to manage a death counter! You can absolutely set this up using a combination of your streaming bot/software and hotkeys. The specific steps will depend on the third-party bot you use for your chat commands (like Streamer.bot, StreamElements, Nightbot, etc.) or if you are using a dedicated counter application. Here are the two main methods: Method 1: Using a Streamer Bot/App with a Global Hotkey Many popular streamer bots and counter apps allow you to assign a global hotkey to an action. If you use Streamer.bot (Recommended for most flexibility): Streamer.bot has a built-in feature to assign a Hot Key Trigger to an Action that runs your command. Create an Action: If you don't have one, create a new Action for your death counter (e.g., "Increment Death Counter"). Add the Sub-Action: Within that new Action, add a sub-action that sends the chat command (e.g., !death+ or whatever your counter command is). This is usually a sub-action like "Twitch/YouTube -> Send Message" or a similar option for your platform. Add the Hot Key Trigger: In the Actions list, right-click your "Increment Death Counter" action and choose Add Trigger. Select Hot Key Press. Configure the key you want to press (e.g., F8, Ctrl + D, etc.). Make sure it's a key or combination you don't use in your game. Test: Save everything and test the key press. It should send the command to your chat without you needing to tab out. If you use a Dedicated Counter Application (e.g., Death Counter and Soundboard App): Some standalone applications are designed specifically for this. They often: Manage the death count and save it to a .txt file. Allow you to assign a global hotkey (like F11 or F12) directly within the app to increment or decrement the number. You then display the number on your stream by using a "Text Source (GDI+ or FreeType)" in OBS/Streamlabs and pointing it to the .txt file generated by the counter app. Method 2: Using Your Streaming Software's Hotkeys to Control a Text Source If you are just using your streaming software (like OBS Studio or Streamlabs Desktop) and a simple .txt file for the counter, you might be able to manage the count directly. If you are using OBS Studio with a Text File: Create a simple text file (e.g., deaths.txt) on your computer and put a starting number (like 0) in it. Add a Text Source in OBS: Add a Text (GDI+ or FreeType) source to your scene. Check "Read from file" and browse to your deaths.txt file. Install a Hotkey Script/Plugin: OBS Studio has community-made LUA scripts or plugins that add the functionality to increment/decrement the count in a text file using a hotkey. Search the OBS forums or Google for an up-to-date "OBS Death Counter Script" or "Text Source Hotkey Incrementer". Once installed and configured, you'll assign the keybind in the OBS Settings -> Hotkeys menu.
