# how do i double check im on the right version 

### USER
how do i double check im on the right version 

### GEMINI
You can double-check the Python version of your active environment by running a simple command in your terminal. Make sure your new virtual environment, blender_ai_env_311, is activated. You'll know it is because the name will appear at the start of your terminal prompt. Then, run this command: python --version The output should be: Python 3.11.9 If you see this, you are on the correct version and can proceed with the next steps.
