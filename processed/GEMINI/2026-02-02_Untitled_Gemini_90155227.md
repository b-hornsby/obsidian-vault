It looks like you're running into Unexpected error (#1) while trying to launch Fall Guys. This specific error is almost always related to the Epic Online Services (EOS) or the Easy Anti-Cheat (EAC) not being correctly initialized within your Wine prefix. Because you are trying to add the game as a standalone executable, pointing to the raw .exe will definitely trigger this error since it bypasses the environment the game needs to "talk" to the anti-cheat servers. 1. Fix the "Unexpected Error (#1)" Before trying to turn it into an executable, you need the game to launch correctly from Heroic. Install Epic Online Services: In your settings screenshot, click RUN EXE ON PREFIX. Navigate to the game's installation folder and look for EpicOnlineServicesInstaller.exe. Run it to ensure the online requirements are met. Enable EOS Overlay: Go to the Other tab in those game settings and ensure Enable EOS Overlay is checked. Toggle Anti-Cheat: Under the Advanced tab, find the EasyAntiCheat Runtime toggle. Sometimes unchecking and re-checking this forces Heroic to correctly link the runtime files needed to prevent that error. 2. Add as a Functional Executable Once the game launches from Heroic, do not use the .exe file in the game folder for Steam or your desktop. Use one of these methods to ensure the fix you just applied actually stays active: The Steam Method (Recommended) In Heroic, go to your Library. Click the three dots on the Fall Guys tile. Select Add to Steam. Restart Steam. The game will appear as a "Non-Steam Game" but will launch through Heroic’s configured environment. The Manual "Executable" Command If you are using a custom launcher or dock, use this command string as your "executable" target: heroic://launch/epic/0a2d9f6403244d12969e11da6713137b Note: That long string of numbers/letters is the AppName visible at the bottom of your second screenshot. This URI tells your system to open Heroic and launch Fall Guys with all your Wine settings intact.
