# So is it a python library or is it a whole separate thing?

### USER
So is it a python library or is it a whole separate thing?

### GEMINI
ROMA is not a separate application but is a Python library that serves as an open-source framework for building multi-agent AI systems. It is designed to be a developer-friendly tool that provides the structure for creating sophisticated, collaborative AI agents. Developers can use the ROMA framework in their own Python projects to build custom agents, connect them to different large language models (LLMs), and integrate various data sources. The framework's core is written in Python, and its open-source nature allows for community-driven development and customization.
