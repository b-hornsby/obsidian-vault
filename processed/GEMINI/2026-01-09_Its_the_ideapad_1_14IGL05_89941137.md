# It’s the ideapad 1 14IGL05

### USER
It’s the ideapad 1 14IGL05

### GEMINI
Since you have the IdeaPad 1 14IGL05, you have run into the "Reset System" bug specific to this model's Intel Pentium/Celeron architecture. This laptop has a very specific conflict with how Linux handles the security chip. You don't need to reinstall. You just need to flip one specific switch in the BIOS that is currently killing the boot process every time it starts. The Solution: Disable Intel PTT The "Reset System" loop on the 14IGL05 is almost always caused by Intel Platform Trust Technology (PTT). When this is on, the GRUB bootloader triggers a hardware security check that fails and forces a reboot before the Mint logo even appears. Shut down the laptop completely. Press the Power Button and immediately start tapping F2 (or Fn + F2) repeatedly until the BIOS menu appears. Use the arrow keys to navigate to the Security tab. Find Intel Platform Trust Technology (it might be labeled as PTT or TPM). Set it to Disabled. While you are there, ensure Secure Boot is also Disabled (usually right below it). Press F10 to Save and Exit. Why this is happening Your laptop uses an eMMC storage chip (not a standard SSD). These chips sometimes have "dirty" partition tables from the factory Windows install. If disabling PTT doesn't work immediately, the BIOS is likely still trying to find the old Windows Boot Manager instead of the new Linux one. If it still loops after disabling PTT: Tap F12 (or Fn + F12) rapidly as soon as you turn it on to open the Boot Manager. Do you see an option that says ubuntu? If YES: Select it. If it boots, your install is fine, but you need to go back into BIOS and move "ubuntu" to the top of the Boot Priority list. If NO: Your installer failed to write to the eMMC correctly. You will need to plug the USB back in, boot into the "Live" version, open a program called GParted, and completely wipe the drive (Device -> Create Partition Table -> GPT) before trying the install one last time. Try disabling PTT first—that is the "silver bullet" for the 14IGL05 model. Does it successfully reach the Linux Mint logo now, or are you still seeing that "Reset System" flash?
