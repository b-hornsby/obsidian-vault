# does tikfinity have something like this? 

### USER
does tikfinity have something like this? 

### GEMINI
Yes, Tikfinity has the ability to create and manage custom counters that you can display on your TikTok LIVE stream, similar to a "death counter." In fact, Tikfinity is a much better tool for this type of feature when streaming on TikTok, because it is specifically designed to interact with the TikTok LIVE platform. Here's how Tikfinity handles custom counters: 1. Custom Goals/Counters Tikfinity allows you to create Goal Overlays that can function as a manual counter: Manual Control: You can set up a custom goal (like a "Death Counter" or "Win Streak") that you, your moderators, or even viewers with a chat command can increase or reset. Overlay URL: Like StreamElements, Tikfinity generates a unique Browser Source URL for this counter. Implementation: You add this URL to TikTok LIVE Studio using the Link Source (or Browser Source) option, and the counter will appear on your stream. 2. Superior TikTok Integration Where Tikfinity truly excels is its native integration with TikTok events, allowing for counters based on actual stream metrics: Tikfinity FeatureWhat It DoesWhy It's Better Than StreamElements on TikTokGift GoalA counter that increases based on the coins from gifts you receive.StreamElements cannot track TikTok gifts.Follower GoalA progress bar or counter that tracks how close you are to your next follower milestone.StreamElements cannot track TikTok follows.Like GoalA counter that increases every time your stream receives a "like" (tap on the screen).StreamElements cannot track TikTok likes. So, you can create the simple, chat-command-driven counter you're looking for, or you can use Tikfinity's superior access to TikTok's data to create goals and counters that are automatically driven by viewer engagement.
