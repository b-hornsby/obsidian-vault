# Can you do that through WSL2 or no?

### USER
Can you do that through WSL2 or no?

### GEMINI
The one-click installer is designed for Windows, so it won't work directly within WSL2. WSL2 is a Linux environment, so you'll need to use the Linux installation method, which typically involves cloning the repository from GitHub and running the setup scripts from the command line.
