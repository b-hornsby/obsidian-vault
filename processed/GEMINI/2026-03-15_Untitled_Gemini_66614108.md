Since you have the [root@cachyos /]# prompt, you are perfectly positioned to finish the job. We just need to fix the bootloader registration and set up that Minecraft theme. 1. Fix the Bootloader Registration Type these commands exactly. They will force your motherboard to recognize CachyOS again. bootctl install sdboot-manage gen Note: If sdboot-manage isn't found, don't worry—the bootctl part is what fixes the BIOS entry. 2. Set Up the "Minegrub" Menu To get the Minecraft-style world selection screen, we need to switch from the default systemd-boot to GRUB. Run these commands one by one: # 1. Install GRUB and the tool to find Windows pacman -S grub os-prober # 2. Install GRUB to your motherboard (replaces systemd-boot) grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB # 3. Download and Install the Minecraft Theme git clone https://github.com/Lxtharia/minegrub-world-sel-theme.git cd minegrub-world-sel-theme sudo cp -ruv ./minegrub-world-selection /boot/grub/themes/ 4. Edit the Config to Enable the Theme: Type micro /etc/default/grub (or nano if micro isn't there). Scroll to the bottom and ensure these lines exist/are added: GRUB_DISABLE_OS_PROBER=false GRUB_THEME="/boot/grub/themes/minegrub-world-selection/theme.txt" Save and Exit (Ctrl+S, Ctrl+Q for Micro; Ctrl+O, Enter, Ctrl+X for Nano). 5. Final Step—Generate the New Menu: grub-mkconfig -o /boot/grub/grub.cfg Look for "Found Windows Boot Manager" and "Found theme" in the output. 3. The Reboot & Final Check Type exit to leave the chroot environment. Restart your PC and mash F2/Delete to enter the BIOS. Go to the Boot tab and make sure "GRUB" or "CachyOS" is now at Priority #1. Save and Exit (F10). You should now see the Minecraft "World Selection" screen!
