# Is there a way to code in cursor from your phone? 

### USER
Is there a way to code in cursor from your phone? 

### GEMINI
Yes, there is a way to interact with and code in Cursor from your phone, primarily through its Web and Mobile Agent platform. This is available through a web interface that functions like a Progressive Web App (PWA), meaning it can be accessed on any mobile browser (like Safari or Chrome) and can be installed to your home screen for a more native app-like experience. 📱 Cursor Web and Mobile Agent This feature allows you to manage and interact with Cursor's AI coding capabilities when you are away from your main desktop IDE. Access: You can visit the dedicated web app at cursor.com/agents on your phone's browser. Functionality: Launch AI Agents: You can start powerful AI coding agents to perform tasks like fixing bugs, building new features, or answering complex questions about your codebase using natural language prompts. Remote Work: The agents run in the cloud, so you can kick off a task from your phone and then pick up the work later in the full Cursor IDE on your desktop. Review and Collaborate: You can review the changes the agent suggests (diffs), create or manage pull requests, and collaborate with team members directly from the web interface. Notifications: You can often receive notifications (including through Slack integration) when a background task is completed by the agent. 🛠️ How to Get the Best Mobile Experience For the most convenient mobile experience, you can install the web app as a PWA: Open the URL: Go to cursor.com/agents in your mobile browser. Add to Home Screen: iOS (Safari): Tap the Share button (the square with an arrow pointing up), and then select "Add to Home Screen." Android (Chrome): Tap the menu icon (three vertical dots), and then select "Install App" or "Add to Home Screen." This will give you an icon on your phone's home screen that launches the Agent interface in a dedicated window, often with better performance and a more integrated feel than a regular browser tab.
