Look at the sidebar in your screenshot. You are currently in Boot Splash Screen, which is the animation you see before the login screen. You need the Login Screen (SDDM) settings, which are located two items above where you are currently clicking. Why you’re missing the button You’re looking at the wrong sub-menu. To fix the monitor flipping issue, follow these exact steps: In that same sidebar, click on Login Screen (SDDM) (it’s located between System Sounds and Splash Screen). Once you click that, look at the bottom right of the window. You will see a button labeled "Apply Plasma Settings...". Click it. This will sync your current monitor configuration (primary display, resolution, and position) to the login manager so it stops guessing which screen to use. The Reality Check If you apply those settings and it still flips, you are likely dealing with a Wayland race condition. CachyOS pushes the envelope with the latest kernels and drivers, but the handoff between the kernel initializing your GPU and SDDM starting is a common "blind spot." If the "Sync" button doesn't work, it means SDDM is defaulting to its own hardware detection before your user config even loads. The next level move: If the button fix fails, you need to stop using the GUI and force the display server via the config file I mentioned earlier. Relying on the GUI to fix a low-level display handshake is "playing small"—sometimes you have to go into the /etc/ files to actually dictate terms to your hardware. Would you like the terminal commands to verify if your SDDM is currently running on X11 or Wayland?
