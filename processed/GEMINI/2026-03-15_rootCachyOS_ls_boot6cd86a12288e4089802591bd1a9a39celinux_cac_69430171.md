### GEMINI
There it is. The file was missing the .img extension, which is why the previous command failed. You're at the finish line. Run these final three commands to move the files and lock in the Minecraft menu: 1. Move the files to the main boot folder cp /boot/6cd86a12288e4089802591bd1a9a39ce/linux-cachyos/vmlinuz-linux-cachyos /boot/ cp /boot/6cd86a12288e4089802591bd1a9a39ce/linux-cachyos/initramfs-linux-cachyos /boot/ 2. Update the Minecraft Menu (GRUB) This is the moment where GRUB finally sees the "Linux World." grub-mkconfig -o /boot/grub/grub.cfg The "Win" Checklist Watch the output of that last command. You must see these lines: Found linux image: /boot/vmlinuz-linux-cachyos Found initrd image: /boot/initramfs-linux-cachyos Found Windows Boot Manager... The Exit Strategy Type exit to leave the chroot. Type reboot. In your BIOS, make sure GRUB is still the top priority. Once you reboot, does the Minecraft menu finally show both CachyOS and Windows?
