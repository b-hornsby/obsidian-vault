# i dont have a .venv

### USER
i dont have a .venv

### GEMINI
You're right. If you don't have a virtual environment created, the previous commands won't work. The .venv is just a folder that contains your isolated Python environment. We need to create that folder first. Create and Activate the New Virtual Environment Open your terminal in the blender ai agent project folder. This is the directory that contains your agents, assets, and environments folders. Then, run the following commands to create and activate the new virtual environment using Python 3.11: py -3.11 -m venv blender_ai_env_311 blender_ai_env_311\Scripts\activate After you run the second command, you should see (blender_ai_env_311) at the start of your terminal prompt. This confirms the environment is active. You can then proceed with installing the libraries.
