### GEMINI
TL;DR: AI Setup Guides Core Tools Hugging Face: The "GitHub for AI." Install pip install transformers to use thousands of free models. Best for developers. Pocket Pal: An iPhone app to run local LLMs. Download and run GGUF models directly on your phone. Ollama: The easiest way to run local LLMs. Install with one click, then type ollama run llama3 in your terminal to get started. LM Studio: An easy-to-use desktop app with a GUI for downloading and chatting with local LLMs. Great for beginners who don't want to use a command line. Advanced Tools Oobabooga: A highly customizable web interface for local LLMs. Requires a more involved setup but offers lots of features. ChromaDB: A simple Python library for storing and searching text data using AI. Perfect for "chatting with your documents." Weaviate: A high-performance vector database. Use Docker to get it running quickly and scale up your AI data storage. Whisper.cpp: The super-fast, C++ version of OpenAI's Whisper for local speech-to-text. Vosk & Silero: Open-source libraries for offline speech recognition (Vosk) and voice activity detection (Silero), respectively. Automatic1111: The most popular web UI for Stable Diffusion image generation. Use the one-click installer. ComfyUI: A more powerful, node-based web UI for image generation. Steeper learning curve, but more control. Experimental Tools LangChain: A toolkit to connect LLMs to other data and tools. It's the "Lego set" for building complex AI apps. LlamaIndex: A framework for connecting LLMs to your private data (e.g., PDFs, documents) to create a searchable knowledge base. CrewAI: A framework for building "teams" of AI agents that work together to complete tasks. Autogen: Microsoft's framework for creating multiple AI agents that talk to each other to solve problems. LangGraph: An extension of LangChain for building complex, cyclical workflows where agents can loop back to previous steps. Coqui TTS & Bark: Open-source tools for high-quality text-to-speech. Bark is especially good at generating non-speech sounds. XTTS: A text-to-speech model known for its ability to clone a voice from a very short audio clip. Docker: A tool to run any application, including AI models, in a self-contained "box" to avoid compatibility issues.
