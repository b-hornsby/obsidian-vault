# how do i do that? 

### USER
how do i do that? 

### GEMINI
To delete the cache, you'll use the rm -rf command in your WSL2 terminal. Here's how: Stop Oobabooga: If it's running, go to your WSL2 terminal where Oobabooga is active and press Ctrl+C. Navigate to the cache directory: cd ~/.cache/huggingface/hub Delete the specific model cache: rm -rf models--sentence-transformers--all-MiniLM-L6-v2 This command will remove the entire folder for that specific embedding model. rm is for "remove," -r means "recursive" (for folders), and -f means "force" (no confirmation prompts). Confirm deletion (optional): You can run ls again to confirm that the models--sentence-transformers--all-MiniLM-L6-v2 folder is gone. Go back to your Oobabooga directory: cd ~/text-generation-webui/ Restart Oobabooga: Make sure you have an active internet connection first (you can ping google.com to check). ./installer_files/env/bin/python server.py Oobabooga will then attempt to re-download the necessary embedding model for superboogav2 into the cache. Once downloaded successfully, it should load without the error on subsequent boots.
