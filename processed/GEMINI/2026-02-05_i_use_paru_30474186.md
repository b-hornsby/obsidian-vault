Here is how you actually get it done. The Execution You have two main choices in the AUR. Don't overthink it, just choose based on your hardware: The Efficient Choice (shadps4-bin): Pre-compiled. Installs in seconds. Use this if you actually want to play games today. paru -S shadps4-bin The Intensive Choice (shadps4-git): Compiles from the latest source code. Use this only if you have a high-end CPU and you need a fix that was pushed to GitHub ten minutes ago. paru -S shadps4-git The Blind Spot Why did you use sudo pacman?
