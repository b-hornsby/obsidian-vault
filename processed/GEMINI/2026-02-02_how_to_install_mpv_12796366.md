# how to install mpv

### USER
how to install mpv

### GEMINI
Since you’re on CachyOS, you have access to the standard Arch repositories as well as the optimized CachyOS repos. Don't just install the basic version; get the one optimized for your architecture to take advantage of the performance gains CachyOS is built for. 1. The Direct Install Open your terminal and run: sudo pacman -S mpv CachyOS typically provides optimized binaries. If you want the absolute latest features and better PipeWire integration, you can also check if mpv-git is available in their repos or the AUR, but the standard package is the most stable starting point. 2. Why this is the "Advisor" Move VLC is a "kitchen sink" player—it brings its own codecs and legacy bloat. MPV is a minimalist, high-performance engine. On a performance-tier distro like CachyOS, VLC is like putting heavy all-season tires on a track car. Native PipeWire Support: Unlike VLC, MPV talks to PipeWire much more fluently. Hardware Acceleration: It handles GPU decoding (VA-API/NVDEC) with significantly less overhead. No "Source Dropping": It doesn't try to reinvent the wheel for every new file; it maintains the stream better between videos. 3. Essential "Pro" Configuration MPV is minimalist by default (it doesn't even have a traditional menu bar). To ensure it outperforms VLC, you need a basic config file. Create the config directory: mkdir -p ~/.config/mpv Create the config file: nano ~/.config/mpv/mpv.conf Paste these high-level defaults: # High quality video output profile=gpu-hq hwdec=auto # Keep the player open after video ends (prevents audio source dropping) keep-open=yes # Audio settings ao=pipewire The Reality Check Installing MPV is easy. The challenge for you is unlearning the VLC interface. MPV relies on keyboard shortcuts (e.g., f for fullscreen, j for subtitles, 9 and 0 for volume). If you find the lack of buttons annoying, you are prioritizing "visual comfort" over "system stability."
