Since you’re on GNOME, you are dealing with the most "opinionated" desktop environment. GNOME’s Wayland implementation (Mutter) is notoriously strict; it doesn't give you a "Lock Mouse" button in the settings because it expects the game to handle it via the pointer-constraints protocol. If your mouse is escaping, the game is failing to communicate with Mutter, or you're running a multi-monitor setup where the "edges" are leaking. Here is the direct, no-fluff plan to fix it: 1. The "Gamescope" Fix (Highly Recommended) On GNOME, this is your best bet. It creates a virtual container for the game. The mouse physically cannot exit the Gamescope window unless you toggle it. Install: sudo pacman -S gamescope Steam Launch Options: Right-click your game > Properties > General > Launch Options: gamescope -H 1440 -W 2560 -f -- %command% (Replace 1440 and 2560 with your monitor's resolution). Why this works: Gamescope acts as a "liar." It tells the game it is in a restricted box, and it tells GNOME that the game is a single, focused surface. 2. The GNOME Extension (The "Soft" Fix) If you don't want to use Gamescope, you need to force GNOME to behave. There is an extension specifically for this. Extension: Barrier or Keep Awake/Lock. Note: Extensions on GNOME can be fragile after updates, but for CachyOS (which stays very current), these are usually maintained. 3. The "Xwayland" Reality Check Most games run through Xwayland (an adapter for older tech). If the cursor is escaping: Open GNOME Settings > Displays. Ensure your displays are not slightly "offset" in the arrangement. If there is a gap or a weird diagonal alignment, the cursor can sometimes get stuck or "leak" through the gaps in the compositor logic. The Brutal Truth on GNOME If you are playing a competitive shooter or a game requiring high-precision flick shots (like CS2 or Overwatch), playing in Windowed or Borderless mode on GNOME Wayland is a strategic error. You are introducing a layer of compositor overhead that can cause slight input lag. Stop trying to make "Borderless" work. Use Gamescope with the -f (fullscreen) flag. It gives you the "lock" you want while allowing you to Super + Tab out instantly without the game crashing or flickering.
