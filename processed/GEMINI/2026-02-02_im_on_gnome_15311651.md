### GEMINI
Running GNOME on CachyOS means you are likely on Wayland, and GNOME's security model is even more strict than KDE's. On GNOME Wayland, applications are intentionally forbidden from listening to keys when they aren't the "active" window. This is why your PgUp works when you're looking at OBS, but "dies" the moment you click into CS2. Since you're using a Stream Deck via OpenDeck, we are going to bypass the keyboard entirely. This is the only way to get 100% reliability on Linux. The Problem with Hotkeys on GNOME In GNOME Wayland, a standard "Hotkey" inside OBS is useless for gaming. You have two choices: The "Command" Workaround: Bind a key in GNOME Settings to run a terminal command that tells OBS to save. The Stream Deck (OpenDeck) Direct Link: This is the superior method. Step 1: Set up the OBS "Remote Control" To talk to OBS without using keys, we use the built-in Websocket. In OBS, go to Tools > WebSocket Server Settings. Ensure Enable WebSocket server is checked. Click Show Connect Info and note the Server Port (usually 4455) and the Server Password. Step 2: Install obs-cmd (The Bridge) CachyOS makes this easy. We need a tiny tool that lets your Stream Deck "talk" to OBS via the command line. Open your terminal and run: sudo pacman -S obs-cmd Test it by running this in your terminal (replace yourpassword with your actual OBS websocket password): obs-cmd --password yourpassword replay save If a notification pops up in OBS saying "Replay Saved," it works. Step 3: Configure OpenDeck Now we make the button on your Stream Deck do the work. Open OpenDeck. Select the button you want to use. Set the Action Type to Run Command (or Execute). Paste the command you just tested: obs-cmd --password yourpassword replay save Save it. Why this is the "Advisor" Solution: Zero Interference: This doesn't use the keyboard buffer at all, so it can't conflict with your CS2 movements. Wayland Proof: Because it uses a network protocol (Websocket) to send the command, GNOME’s security "keylogging" protection doesn't even see it. Consistency: It will work whether OBS is minimized, hidden, or on a different workspace. Final Check for CS2 CS2 on Linux can sometimes "grab" the mouse and keyboard so aggressively that even background commands lag. If the clip doesn't save instantly, ensure you have "Allow Background Processing" enabled in your CachyOS power settings.
