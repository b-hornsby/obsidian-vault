# how do i do a thorough check for vs code to make sure it's completely uninstalled?

### USER
how do i do a thorough check for vs code to make sure it's completely uninstalled?

### GEMINI
You're right to be thorough, especially given the persistent issues you've faced. A "complete" uninstall of VS Code involves more than just running the uninstaller, as it often leaves behind user settings, extensions, and cached data. Here's a step-by-step process to perform a thorough check and removal of all VS Code components on Windows: Phase 1: Pre-Uninstall Steps Backup your config.yaml: This is crucial as it's not part of VS Code's core installation and will remain. Copy your config.yaml file from C:\Users\Bryan\.continue\config.yaml to a safe place like your Desktop or Documents folder. Close all VS Code instances: Make sure every VS Code window is closed. Check Task Manager for lingering VS Code processes: Press Ctrl + Shift + Esc to open Task Manager. Go to the "Details" tab. Look for any processes named Code.exe or code.exe. If you find any, select them, and click "End task". Phase 2: Running the Uninstaller Use Windows "Apps & features" to uninstall: Go to Start > Settings > Apps > Apps & features. Scroll down or use the search bar to find "Visual Studio Code". Click on "Visual Studio Code" and select "Uninstall". Follow any on-screen prompts. The uninstaller usually asks if you want to delete user data – confirm yes if prompted. Phase 3: Manually Deleting Residual Files and Folders Even after the uninstaller runs, some critical folders might remain. You need to delete these manually. Delete VS Code User Data Folder (Roaming AppData): Press Windows Key + R to open the Run dialog. Type %APPDATA% and press Enter. This will take you to C:\Users\YourUsername\AppData\Roaming. Look for a folder named Code (for stable VS Code). Delete this entire Code folder. Delete VS Code Local AppData Folder (for cached data): Press Windows Key + R to open the Run dialog. Type %LOCALAPPDATA% and press Enter. This will take you to C:\Users\YourUsername\AppData\Local. Look for a folder named Programs\Microsoft VS Code (this contains the actual program files for User-installed versions). Look for a folder named Code (this might contain additional cached data). Delete both of these folders if they exist. Delete VS Code Extensions Folder: Press Windows Key + R to open the Run dialog. Type %USERPROFILE%\.vscode\extensions and press Enter. This will take you directly to the user's extensions directory. Delete all contents within this extensions folder. (The .vscode parent folder might also contain extensions if you didn't install the System-wide version). Check Program Files (for System-wide installations): Open File Explorer and navigate to C:\Program Files\Microsoft VS Code\ If this folder still exists after uninstalling, delete it. Also check C:\Program Files (x86)\Microsoft VS Code\ if you think you might have installed an x86 version. Phase 4: Registry Cleanup (Optional, but good for thoroughness) This step is more advanced and should be done carefully. Incorrect registry edits can cause system instability. Open Registry Editor: Press Windows Key + R, type regedit, and press Enter. Click "Yes" if prompted by User Account Control. Navigate to and delete relevant keys: Backup the registry first: Before deleting anything, click File > Export... and save a backup of your entire registry. For User-level installs: HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Uninstall\Microsoft VS Code_is1 (or similar, look for "VS Code" in the DisplayName) HKEY_CURRENT_USER\Software\Microsoft\VisualStudio Code For System-level installs: HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\{Some-GUID} (look for "Visual Studio Code" in the DisplayName on the right pane, then delete the GUID folder on the left). HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\VisualStudio Code Carefully delete any keys clearly related to "Visual Studio Code". Double-check before deleting. Phase 5: Final System Restart Restart your computer. This ensures all changes take effect and any cached data or processes are truly cleared. After these steps, your system should be as free of VS Code traces as possible. You can then proceed with a fresh installation.
