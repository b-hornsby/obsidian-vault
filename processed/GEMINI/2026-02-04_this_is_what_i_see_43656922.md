You are currently looking at a basic config.jsonc that lists only the modules (the data points like OS, Kernel, etc.) but lacks the logo object. Because the logo line isn't there, fastfetch defaults to your system logo—in this case, CachyOS. To change it to KDE, you need to manually insert the logo configuration into the JSON structure. The Fix: Edit your Config In your micro editor, modify the file so it looks like this: { "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/master/doc/json_schema.json", "logo": { "source": "kde", "type": "auto" }, "modules": [ "title", "separator", // ... rest of your modules ... ] } Steps to execute: Insert the block: Place the "logo": { ... }, block right after the $schema line and before the "modules": [ line. Watch your commas: Ensure there is a comma after the closing brace of the logo block—JSON will break if you miss it. Save: Press Ctrl+S to save and Ctrl+Q to quit in the micro editor.
