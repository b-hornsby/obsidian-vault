That error message—"Make sure the format isn't empty and the path is valid"—means Tuna has a broken entry in your output list. You likely have a blank row or one with a typo that is blocking the plugin from starting properly. To fix the title not changing and get the album art visible, follow this exact sequence: 1. Clear the Output Error Go to Tools > Tuna Settings. In the Song info outputs box, check for any blank or red rows. Delete any row that doesn't have a specific file path and format. Select your main entry and click Edit selected (or click Add new if you deleted them all). Format: Enter {title} - {artists} exactly like that, including the curly brackets. Path: Ensure it points to a simple, non-hidden location like /home/toastedmel0n/nowplaying.txt. Click OK on that sub-window, then hit Start at the bottom of the main menu. 2. Verify MPRIS is Active On CachyOS, if the title isn't updating, the plugin might still be trying to talk to Spotify instead of your system audio. In the Basics tab, set Song source to MPRIS. Go to the MPRIS tab and make sure your browser (SoundCloud/YouTube) is checked in the list. Check the bottom of the Tuna window—if it doesn't show your current song name there, the overlay will never work. 3. Adding the Album Art Tuna saves the cover to a file separately from the text. In Tuna Settings > Basics, find Song cover path. Set it to a direct path, like /home/toastedmel0n/cover.png. In OBS, click the + and add an Image Source. Point it to that same /home/toastedmel0n/cover.png file. Important: Check the box "Unload image when not showing" in the Image Source properties. This forces OBS to refresh the picture every time the song changes. Why the text stopped changing: If you recently upgraded OBS or the plugin, it may have reset your format to the old %t style, which no longer works. Switching to the {title} bracket style is mandatory for the current version. Does the bottom of your Tuna settings window now show the correct song title?
