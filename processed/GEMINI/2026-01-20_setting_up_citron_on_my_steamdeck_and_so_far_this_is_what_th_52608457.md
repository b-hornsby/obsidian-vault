### GEMINI
You’re asking for the "proper" way because you’ve already felt the pain of a broken file path or a corrupted prefix. On a Steam Deck, especially when using AppImages and symbolic links (symlinks), the margin for error is slim. Your setup—linking /home/internal_games to the SD card—is clever for organization but adds a layer of complexity. If you "break" it again, it’s likely because you’re confusing the ROM file (the base game) with the NAND (where updates and DLC actually live). Here is the objective reality of how Citron (and its Yuzu-based lineage) handles updates: You do not "patch" the ROM file itself. You install the update to the emulator's virtual file system. The Tactical Breakdown 1. Locate your NAND (The Virtual Flash Memory) Citron doesn't overwrite your .nsp or .xci files in your internal_games folder. When you "install" an update, Citron copies those files into its own internal folder structure. Path: ~/.local/share/citron/nand/system/Contents/registered/ The Risk: If you have limited space on your internal SSD, installing a 10GB update will consume 10GB of your internal drive, even if your base ROM is on the SD card. 2. The Execution (The "Safe" Way) Do not try to move files manually in Desktop mode. Use the Citron GUI to ensure the database entries are updated correctly. Open Citron in Desktop Mode. Go to File > Install Files to NAND... Select your update file (.nsp or .zip containing the nsp). Wait. If the Steam Deck looks like it’s frozen, it’s just the slow write speed of the internal eMMC/SSD competing with the CPU. Do not force quit. 3. Steam ROM Manager (SRM) Check Since you are using SRM to launch games directly, you don't need to do anything new in SRM. SRM points to the Base ROM in your internal_games folder. Citron, when launched, checks its nand folder, sees an update for that Title ID, and overlays it automatically. The Blind Spot: If you ever delete the Citron AppImage or clear its configuration, your updates vanish, but your base games remain. Why You "Broke It" Before: The Common Pitfalls Version Mismatch: You tried to install an update meant for a different region (e.g., US update on a EU base game). Citron will say "Success," but the game will launch the base version or crash. Symlink Breakage: If you moved the update file after installing it, it doesn't matter (Citron copies it). But if you tried to "link" the NAND folder to the SD card to save space and didn't set the permissions correctly, the emulator loses the ability to write to it. Firmware/Keys: If the update requires a higher firmware version than what you have installed in Citron, the game will black-screen.
