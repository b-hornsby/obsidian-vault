Often, in Oobabooga extensions like Coqui TTS, the first time you select a model from the dropdown that isn't already downloaded, it will start downloading it automatically. Previewing Voices: Type some test text into the "Preview text" box (e.g., "Hello, I am your helpdesk AI assistant."). Click the "Preview" button next to it. Automatic Playback: Ensure "Play TTS automatically" is checked if you want the AI's responses to be spoken without clicking a button each time.
