# would character be where i put the system prompt? 

### USER
would character be where i put the system prompt? 

### GEMINI
Yes, based on image_39d662.png, the "Context" box under the "Character" tab is where you would put your system prompt. The "Character" tab is designed for defining the AI's persona and background, and the "Context" box is precisely where you provide those overarching instructions that guide the model's behavior throughout the conversation. You can also use the "Greeting" box to set an initial message the AI sends when a new chat starts, which can be part of establishing its helpdesk persona. For instance, "How can I help you today?" is a good default.
