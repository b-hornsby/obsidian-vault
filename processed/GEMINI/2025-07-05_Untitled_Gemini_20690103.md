Navigate to the "Web Retrieval-Augmented Generation" tab (which is the tab shown in your image_cbcb07.png screenshot). At the very top of this tab, check the box for "Activate Web RAG". Save Settings: There might be a "Save settings" or "Apply" button within this tab, or you might need to go back to the "Extensions" tab and save/restart again to ensure this activation is persistent. Now, let's understand how web_rag works, based on the options in your screenshot: AUTO Mode vs. DIRECT Mode: AUTO: This is for general web searches. You start your prompt with a specific key phrase (default is "web,"). The extension then takes the rest of your prompt, converts it into a search query, uses the "URL template" (default is DuckDuckGo Lite), performs the search, retrieves data, and injects it into the LLM's context. DIRECT: This is for when you have a specific URL you want the AI to read. You start your prompt with another key phrase (default is "get") followed by the full URL. URL Template: https://lite.duckduckgo.com/lite/?q=%q. The %q will be replaced by your search query. DuckDuckGo Lite is used for simpler parsing. Start/End Markers: [ Next Page > ] and 6.. These are for telling the extension what content to scrape from the retrieved webpage (it will start capturing data after "Start" text and end before "End" text, or based on max characters). You generally don't need to change these unless you're fine-tuning scraping for specific sites. Step 2: Test Web RAG in AUTO Mode Let's try the AUTO mode first, as it's more straightforward for general questions. Go to the "Chat" tab in Oobabooga. Ensure you are in chat-instruct mode. In the "send a message" input box, type a question that requires current or general web knowledge, starting with the AUTO key phrase: web, What is the current population of Tokyo? (Note the comma after "web" if you keep the default setting) Click "Generate." What to look for to confirm it's working: Terminal Output: You should see activity in your WSL2 terminal indicating that web_rag is performing a web request, processing data, and potentially adding embeddings. Look for messages related to web fetching or data processing. AI's Response: The AI's response should reflect information likely pulled directly from a web search result, answering your question accurately. Context Injection (less common for web_rag to show this directly to user): Similar to superboogav2, web_rag will inject the retrieved web content into the prompt given to the LLM.
