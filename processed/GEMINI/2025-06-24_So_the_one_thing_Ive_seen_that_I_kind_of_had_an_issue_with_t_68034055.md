Ah, that could definitely be it! Installing the model before Oobabooga is set up can cause some confusion. Oobabooga expects the models to be in a specific location within its own directory structure. Also, using the wrong GitHub link can lead to problems. It's best to grab the link directly from the official Oobabooga GitHub page to make sure you have the right one.
