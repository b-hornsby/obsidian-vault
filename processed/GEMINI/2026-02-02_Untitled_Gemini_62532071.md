To add a game from Heroic Launcher as a standalone executable (e.g., for Steam or a desktop shortcut), you should not point directly to the game's .exe file. Doing so bypasses the Wine prefix and compatibility settings Heroic manages, which often causes games like Fall Guys to trigger "Unexpected error (#1)". Instead, use Heroic’s built-in tools or its URI scheme to create a functional launcher. 1. The Easiest Way (Built-in Export) Heroic can automatically create standalone shortcuts that keep your Wine/Proton settings intact: To Steam: Go to your Library in Heroic, click the three dots on the game tile, and select Add to Steam. Restart Steam to find it in your library. To Desktop/Application Menu: Click the three dots on the game's page and select Add Shortcut. This creates a .desktop file (on Linux) or a shortcut (on Windows) that acts as the executable. 2. The URI Scheme (For Custom Launchers) If you need a specific "executable path" for a custom dock or script, use the Heroic URI scheme. This tells the system to launch the game through Heroic with all necessary configurations: Format: heroic://launch/<provider>/<game-id> Finding the ID: You can find the App Name or ID in the game's settings or by right-clicking the game and selecting Copy Game ID. Example for Fall Guys: heroic://launch/epic/0a2d9f6403244d12969e11da6713137b 3. Fixing "Unexpected error (#1)" (EAC Fix) If you are seeing this error specifically with Fall Guys, it is likely because Epic Online Services (EOS) or Easy Anti-Cheat (EAC) is not properly installed in the game's prefix. Before adding it as an executable, follow these steps: Install EOS: In the game's settings in Heroic, click Run EXE on Prefix and navigate to your game's installation folder. Select and run EpicOnlineServicesInstaller.exe. Enable Overlay: Go to the Other tab in the game settings and ensure Enable EOS Overlay is checked. Toggle Anti-Cheat: In the Wine Extensions or Advanced section, ensure EasyAntiCheat Runtime is checked. High Core Count Fix: If you have a high-end CPU, some EAC versions fail.
