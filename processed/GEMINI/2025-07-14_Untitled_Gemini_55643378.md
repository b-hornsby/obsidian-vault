You're getting the "Not enough free space" error in MiniTool Partition Wizard because the partition you're trying to extend ("E:4tb drive") is a Primary Partition, and the unallocated space next to it (1678.02 GB) is a Logical Partition (indicated by the green outline/hatching in Disk Management). You can't directly extend a Primary partition into a Logical unallocated space. To combine these, you need to either: Delete the existing "E:4tb drive" partition and the unallocated space, then create a single new partition. This is the simplest and most reliable method if you don't have any data on the "E:4tb drive" that you need to save. Convert the unallocated space to be the same type as your "E:4tb drive" (Primary), or vice versa, then extend. This is more complex and involves multiple steps that carry more risk. Given your goal is to have the full 4TB, the first option (deleting all partitions on Disk 1 and starting fresh) is the safest and most straightforward way to resolve this when you have non-contiguous or mixed partition types on an external drive. ⚠️ Warning: This will erase ALL data on Disk 1. If you have any data on the current "E:4tb drive" (2048 GB), BACK IT UP NOW to another drive. There's no way to recover data after this process. Steps to Format Your Drive to Full Capacity (Recommended) Open MiniTool Partition Wizard. Select Disk 2 (Your 4TB External Drive): In MiniTool Partition Wizard, look at "Disk 2." You'll see "E:4tb drive" and the "1678.02 GB Unallocated" space. Delete the "E:4tb drive" Partition: Right-click on the "E:4tb drive" partition. Select "Delete" from the context menu. This will turn the "E:4tb drive" partition into unallocated space. Delete the 1678.02 GB Unallocated Space (if it's still separate/logical): Even though it's unallocated, if it still shows a green border or is listed as "Logical," it might be treated as a separate entity. Right-click on this "1678.02 GB Unallocated" space. Select "Delete" or "Delete All Partitions" if that option appears. After these steps, Disk 2 should show one single, large "Unallocated" space (around 3726 GB) without any green borders or separate entries. Create a New Partition: Right-click on the entire large "Unallocated" space for Disk 2. Select "Create." In the "Create Partition" window: Partition Label: Type a name like "My 4TB Drive." File System: Choose NTFS (for Windows compatibility) or exFAT (for Windows and Mac compatibility). Size and Location: Ensure the slider is all the way to the right, using the maximum possible size. Create As: Choose "Primary" (this is important for maximum compatibility and to avoid issues like the one you're currently facing). Click "OK." Apply the Changes: In the main MiniTool Partition Wizard window, you'll see the pending operations. Click the "Apply" button (bottom-left, blue checkmark icon). Confirm the operation by clicking "Yes" when prompted. MiniTool Partition Wizard will then execute these operations, formatting your entire 4TB drive into a single, usable partition. This should resolve the "Extend Volume" greyed-out issue and the "Not enough free space" error.
