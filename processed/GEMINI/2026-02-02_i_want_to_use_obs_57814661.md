If you want to use OBS, you need to set it up correctly so it doesn't "fight" your system. Using the Replay Buffer is the exact equivalent of "clipping." Here is your prioritized plan to stop the lag and get clips working on GNOME. Step 1: Clean Up (Delete the Lag) The reason Gamescope was lagging is because it was a "middle-man" OBS was trying to record. Go to Steam > Right-click Halo MCC > Properties. Delete all launch options. In-game: Set the game to Exclusive Fullscreen or Borderless Windowed. Turn Vsync OFF. Step 2: Configure OBS for Clipping (Replay Buffer) Don't just record; use the Buffer so you don't fill your hard drive with junk. Open OBS Settings > Output: Set Output Mode to Advanced. Go to the Recording tab. Set a Recording Path (where clips go). Set Encoder to NVIDIA NVENC (if NVIDIA) or VAAPI/AMF (if AMD). Do not use x264; it will lag your game. Enable the Buffer: Go to the Replay Buffer tab. Check Enable Replay Buffer. Set Maximum Replay Time to your clip length (e.g., 60s). Set the Hotkey: Go to Settings > Hotkeys. Find "Save Replay" and set it to something like Alt + F10. Step 3: Use the Correct Capture Method (Wayland) On GNOME Wayland, "Display Capture" is inefficient and can cause the cursor issues you saw. Add a new Source: Screen Capture (PipeWire). When the GNOME pop-up appears, select the specific window of Halo MCC (not the whole screen). The Secret Sauce: Install obs-vkcapture. Run: sudo pacman -S obs-vkcapture In Steam launch options, put: obs-gamecapture %command% In OBS, add the source "Game Capture (Vulkan)". This is the absolute lowest-latency way to record on Linux. Step 4: Fix the Mouse Leak (The GNOME Way) Since you aren't using Gamescope to trap the mouse, do this: Open your browser and go to GNOME Extensions: Mousetrap. Install it. Now, when you play Halo, hit the toggle in your top bar. Your mouse is now physically caged in that window. The Strategy: Why this works You were trying to solve a Mouse Problem with a Video Tool (Gamescope), which broke your Recording Tool (OBS). The Correction: Use a Window Tool (Mousetrap extension) to lock the mouse, and a Recording Tool (OBS with Replay Buffer) to clip.
