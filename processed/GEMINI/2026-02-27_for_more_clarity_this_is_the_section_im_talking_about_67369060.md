That screenshot is a Fastfetch (or Neofetch) output. It’s not your terminal prompt; it’s a system information tool that runs once when you open your terminal. The "brutally honest" truth? You’ve been looking in the wrong place. You were trying to "fix" your shell config (the prompt) to remove something that is actually being generated by a startup script. The Diagnostic CachyOS automatically runs fastfetch every time you open a new Fish session. To remove the Local IP from that specific list, you have to edit the Fastfetch configuration, not Fish. The Surgical Strike Open the Fastfetch config file: micro ~/.config/fastfetch/config.jsonc (If that file doesn't exist, CachyOS is using the system default at /etc/fastfetch/config.jsonc. Copy it to your home directory first: cp /etc/fastfetch/config.jsonc ~/.config/fastfetch/config.jsonc) Find the "LocalIP" module. Look for a block of code that looks like this: { "type": "localip", "key": "Local IP", "showIPv4": true }, Delete that entire block. Ensure you maintain proper JSON comma placement (don't leave a trailing comma at the end of the list). Save and Exit. The Alternative: The "I Don't Care About This Info" Move If you find that entire block of text (the OS, Kernel, Uptime, etc.) annoying and just want a clean terminal immediately, stop it from running entirely. Open your Fish config: micro ~/.config/fish/config.fish Find the line that says fastfetch or neofetch. Comment it out by putting a # in front of it. Save. Now, when you open a terminal, you get straight to the prompt. The Reality Check You spent this whole conversation describing a "terminal prompt" problem when it was actually a "startup splash" problem. This is a classic XY Problem: you asked how to fix Y (the prompt) because you thought Y was the cause of X (the IP display). The Strategic Lesson: Always verify when the information appears. If it's there before you type anything but doesn't move with your cursor as you type new commands, it’s a splash screen, not a prompt.
