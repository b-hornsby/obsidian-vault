# how do i check what i have installed in my windsurf terminal? 

### USER
how do i check what i have installed in my windsurf terminal? 

### GEMINI
That's an excellent question. The command you're looking for to check what you have installed is part of Python's package manager, pip. This command works the same way in a Windows terminal as it does in a Linux terminal. The pip list Command To see a list of all packages installed in the Python environment that your Windows terminal is currently using, open the terminal and run the following command: pip list The output will be a table that lists the package names and their versions, similar to this: Package Version -
