To add a game from Heroic Games Launcher as a standalone executable (e.g., for use in Steam, a custom dock, or a script), it is important to use Heroic's built-in tools or its URI scheme. Simply pointing to the game's .exe file usually fails because it bypasses the necessary Wine/Proton environment Heroic manages. 1. The Simplest Method: Use Heroic's "Add to" Tools Heroic has built-in features to export games as executables for specific platforms: For Steam: Open your Library in Heroic, click the three dots on the game tile, and select Add to Steam. Restart Steam to see the game in your library. For Desktop/Application Menu: Click the three dots on the game’s page and select Add Shortcut. This creates a .desktop file (on Linux) or a shortcut (on Windows) that acts as a standalone executable launcher. 2. Using the URI Scheme (For Custom Launchers) If you need a command for a custom script or a launcher like Pegasus, use the Heroic URI scheme. This ensures the game launches with the correct prefix and Wine version: Command Format: heroic://launch/<provider>/<game-id> (e.g., heroic://launch/epic/66033). Finding the ID: You can find the App Name or ID in the game's Settings or by right-clicking the game tile and selecting Copy Game ID. 3. Creating a Custom Linux Script If you want a physical file that functions as an executable, you can create a bash script: Create a file named launch_game.sh. Paste the following (adjusting for your installation method): #!/bin/bash # For Flatpak users: flatpak run com.heroicgameslauncher.hgl heroic://launch/epic/YOUR_GAME_ID Make it executable: chmod +x launch_game.sh. 4. Special Case: Fix for "Unexpected Error #1" (e.g., Fall Guys) If you are trying to launch a specific game like Fall Guys and it fails with "Unexpected Error #1," this is often due to Anti-Cheat or Online Service issues rather than the executable path itself. Enable EOS Overlay: In the game's settings (three dots), ensure Enable EOS Overlay is checked. Install Epic Online Services: Use the Run EXE on Prefix option in Heroic settings to manually run EpicOnlineServicesInstaller.exe located inside the game's installation folder. Anti-Cheat Toggle: Some users find that unchecking and then re-checking the EasyAntiCheat Runtime box in the game settings forces a necessary installation/repair.
