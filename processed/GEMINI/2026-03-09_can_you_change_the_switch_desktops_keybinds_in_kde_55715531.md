# can you change the switch desktops keybinds in kde? 

### USER
can you change the switch desktops keybinds in kde? 

### GEMINI
Yes, you can absolutely remap these in KDE Plasma. Since you're on CachyOS, you're likely running Plasma 6, which has a very streamlined shortcuts menu. Here is the direct path to change them: 1. The Direct Path Open System Settings. Go to Keyboard > Shortcuts. Click on Commands or search for "KWin" in the list of applications/components. Look for the following specific entries: Switch One Desktop to the Left / Right: This is what you use to cycle through them. Switch to Desktop 1, 2, 3, etc.: Use this if you want "Hyprland-style" direct jumping (e.g., Meta + 1). 2. Strategic "Vibe Coding" Style Setup Since you mentioned using "vibe coding" and a Linux workflow, you might want to mimic tiling window managers for efficiency. Many power users on CachyOS do this: Remap Meta + 1-4 to Switch to Desktop 1-4. Remap Meta + Shift + 1-4 to Window to Desktop 1-4. This lets you stay on the home row and manage your instances without reaching for F keys or Ctrl+Alt combos. 3. Don't Forget "Navigation Wraps Around" If you set up hotkeys to switch left/right, it can be annoying if you hit a "dead end" at your last desktop. Go to System Settings > Workspace Behavior > Virtual Desktops. Ensure Navigation wraps around is checked. This turns your desktop line into a loop.
