Since you want the Minecraft (Minegrub) menu, we are going to switch you from the default systemd-boot to GRUB right now while you have the hood open. 1. Install GRUB and OS-Prober Run this command to get the necessary tools to manage the boot menu and find Windows: pacman -S grub os-prober 2. Install GRUB to the Motherboard This command tells your ASUS motherboard that GRUB is the new boss: grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB 3. Setup the Minecraft Theme Run these to download and move the theme files: git clone https://github.com/Lxtharia/minegrub-world-sel-theme.git cd minegrub-world-sel-theme sudo cp -ruv ./minegrub /boot/grub/themes/ 4. Configure GRUB to show Windows and the Theme Open the config file: micro /etc/default/grub (If micro isn't installed, use nano /etc/default/grub) Scroll to the very bottom and add these lines: GRUB_DISABLE_OS_PROBER=false GRUB_THEME="/boot/grub/themes/minegrub/theme.txt" Save and Exit: (If using micro, press Ctrl+S then Ctrl+Q. If nano, Ctrl+O, Enter, then Ctrl+X). 5. Final Step: Generate the Menu This is the most important part. It stitches everything together: grub-mkconfig -o /boot/grub/grub.cfg Watch the output: It should say "Found Windows Boot Manager" and "Found theme." The Reboot Type exit and hit Enter. Reboot your PC. Mash F2/Delete to enter BIOS. Ensure "GRUB" or "CachyOS" is now at the top of the Boot Priority. Save and Exit (F10). You should be greeted by the Minecraft world selection screen. I see the list. You need to pick your actual Linux install, not the Windows one. Looking at your screen: /dev/nvme0n1p2 is your Btrfs partition (CachyOS). This is the one you want. /dev/nvme0n1p4 and p5 are the NTFS partitions Windows just created. Do not pick those. The Steps: Use your arrow keys to highlight Partition: /dev/nvme0n1p2: FS: btrfs. Hit Enter. It will ask if you want to mount any other partitions (like the EFI/boot partition). Say Yes to mounting the EFI partition if it asks specifically about /dev/nvme0n1p1. Once the prompt changes to something like [root@cachyos /]#, run the recovery commands: sudo bootctl install sudo sdboot-manage gen If sdboot-manage gen gives you an error, don't sweat it. The bootctl install command is the heavy lifter that forces your ASUS motherboard to see the "CachyOS" boot option again. Once those are done, type exit, reboot, and mash F2 to check your BIOS again.
