# So, if I'm thinking like it's like right here, it's going down. I'm thinking like the next support if it were to go short from this level would be around here. So, if I were to do that, how would I set that up over here?

### USER
So, if I'm thinking like it's like right here, it's going down. I'm thinking like the next support if it were to go short from this level would be around here. So, if I were to do that, how would I set that up over here?

### GEMINI
If that's your estimated support level, that would be your Take Profit price. You'd put that price in the TP Price field. Then, you'd set your Stop Loss a safe distance above your entry price to manage your risk.
