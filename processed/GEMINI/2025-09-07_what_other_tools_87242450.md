# what other tools? 

### USER
what other tools? 

### GEMINI
The BlenderScriptRunner is the most important tool, but your project blueprint includes several others. Each one is a custom piece of code that gives an agent a specific ability. The Other Custom Tools Delegation Tool (for the Director Agent): This tool is more of an internal function. Its job is to help the Director agent break down a high-level creative request (like "make a crypto animation") into smaller, sequential tasks for the other agents (like "generate environment," "load assets," etc.). Skybox AI API (for the Environment Agent): This tool will handle the communication with an external AI service. It would take a text prompt (e.g., "futuristic cityscape at night") and send it to Skybox AI to get a generated 3D environment or texture back. Local 3D Library API (for the Asset Agent): This tool will be your bridge to your assets/ folder. Its purpose is to find and load the correct 3D models and textures from your local library so they can be prepared for the scene. Blender Renderer Tool (for the RenderAndPolish Agent): This tool is similar to the BlenderScriptRunner in that it will also use subprocess to call Blender. However, its specific job is to run the final rendering process, setting the output format, frame range, and render engine.
