### GEMINI
In CachyOS with the Limine bootloader, you are editing the source file that tells the system how to build your boot menu. The Precise Location Open the file with this command: sudo nano /etc/default/limine Where to add the line You will see a block of text that looks like this: SP_PATH="/boot" KERNEL_CMDLINE[default]+="quiet nowatchdog splash rw rootflags=subvol=/@ root=UUID=..." BOOT_ORDER="*, *lts, *fallback, Snapshots" Add the new parameter directly inside the quotes of the KERNEL_CMDLINE[default] line, right at the very end. It should look like this: KERNEL_CMDLINE[default]+="quiet nowatchdog splash rw rootflags=subvol=/@ root=UUID=... usbcore.autosuspend=-1" Crucial Next Steps Simply saving the file won't change anything because Limine needs to "regenerate" its entries. Press Ctrl+O then Enter to save, and Ctrl+X to exit. Run the update command to push these changes into your bootloader: sudo limine-mkinitcpio Reboot your machine. The "Advisor" Mirror If you reboot and cat /proc/cmdline still doesn't show that flag, you've missed a space or a quote. On CachyOS, the system is unforgiving of syntax errors in boot files. Verify the fix immediately after rebooting: Run: cat /sys/module/usbcore/parameters/autosuspend If it returns -1, the kernel is no longer allowed to touch your Yeti's power. If it returns anything else, the bootloader didn't update and we need to look at your syntax. Would you like me to double-check your lsusb -t output after the reboot to ensure the Yeti hasn't moved back to the crowded Bus 001?
