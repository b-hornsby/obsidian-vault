### GEMINI
Switching to Eden while moving your library to the internal SSD is the right move for performance and stability. Because you’re using SAK-merged files, we’re going to set this up so you never have to touch an "Update Manager" again. Here is the objective, step-by-step plan to migrate and ensure everything is "substantiated" correctly. Phase 1: Clean Up & Prep (Internal SSD) Move the ROMs: Open the Dolphin File Manager. Go to your SD card, cut your Switch ROMs, and paste them into /home/deck/Emulation/roms/switch/ on your internal SSD. Ensure Path Clarity: Rename your merged Zelda file to something simple like totk_merged.xci. Avoid brackets or symbols. Kill Citron: In Desktop Mode, find the Citron AppImage and delete it. In Steam, right-click the old Citron shortcut and select Manage > Remove non-Steam game. Phase 2: Install & Configure Eden Download Eden: Get the latest Linux-amd64.AppImage from the Eden GitHub Releases. Placement: Move the file to /home/deck/Applications/. Rename it to exactly eden.AppImage. Permissions (Crucial): Right-click the file > Properties > Permissions > Check "Is Executable". Initial Run: Double-click eden.AppImage to open it. Keys/Firmware: Go to File > Open Eden Folder. Drop your prod.keys into the keys folder. Install your firmware via Tools > Install Firmware. Pathing: Go to Add New Game Directory and select your internal /home/deck/Emulation/roms/switch/ folder. Verify: If your SAK-merged game shows up with the correct version number (e.g., v1.2.0), the file is "substantiated" and healthy. Phase 3: The "Symlink" for EmulationStation You want EmulationStation (ES-DE) to look at the internal SSD, but ES-DE usually looks at the SD card if that's where EmuDeck was installed. Go to your SD Card's roms folder: /run/media/mmcblk0p1/Emulation/roms/. Delete the empty switch folder there. Open a second Dolphin window and go to the Internal SSD: /home/deck/Emulation/roms/. Right-click and drag the switch folder from the SSD window into the SD card window. Select "Link Here". Result: ES-DE will check the SD card, see the link, and immediately jump to the internal SSD to read your games. Phase 4: Finalizing the Launchers (The SRM Fix) To prevent the "infinite launch" you had before: Open EmuDeck and go to Manage Emulators. Find Eden and click Reset Configuration. This ensures EmuDeck knows where the AppImage is. Open Steam ROM Manager. Find the Nintendo Switch - Eden parser. Check the Executable Path. It should be pointing to your eden.AppImage in the Applications folder. Check the Start In field. Ensure it is blank or points to /home/deck/Applications/. Click Parse, then Save to Steam. Phase 5: The "Brutal" Verification Before going to Game Mode, do this: In Steam (Desktop Mode), right-click your new Eden shortcut > Properties. Look at Target. It should look like: "/home/deck/Applications/eden.AppImage" -g "/home/deck/Emulation/roms/switch/totk_merged.xci" Ensure there are no quotes in the "Start In" box.
