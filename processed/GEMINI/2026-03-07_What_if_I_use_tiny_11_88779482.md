# What if I use tiny 11?

### USER
What if I use tiny 11?

### GEMINI
Using Tiny11 (a stripped-down version of Windows 11) is a much better strategic move than using standard Windows 10 or 11 on that 120GB SSD. In 2026, where Windows 10 is officially "dead" and unsupported, Tiny11 solves your two biggest problems: storage space and system bloat. However, because you want to play Fortnite and COD, there are some specific "2026-era" traps you need to avoid. 1. The Storage Win (Tiny11 vs. Standard) A standard Windows 11 install takes up ~30–40GB and balloons quickly with "WinSxS" folders and updates. Tiny11: Takes up only ~8GB to 12GB of disk space. The Result: On your 120GB SSD, you’ll have over 100GB of free space. This is enough to actually fit Fortnite (currently ~30–50GB) directly on the SSD, which will solve the texture-loading issues I warned you about. 2. The Anti-Cheat Warning (Fortnite & COD) This is where you must be careful. As of early 2026, Fortnite and Call of Duty have ramped up their kernel-level anti-cheat requirements. The Risk: Many "debloated" ISOs found online remove Windows Defender or Windows Update components. Some anti-cheats (like Ricochet or BattlEye) flag the system as "tampered with" if these core security services are missing. The Fix: Don't download a random "Tiny11.iso" from a shady site. Use the Tiny11 Builder script on GitHub. It lets you take an official Microsoft ISO and strip it yourself while keeping the "identity" and security components intact so the games don't ban you. 3. TPM and Secure Boot (The 2026 Standard) Since you have a Z790 motherboard and a 12th Gen i7, your hardware fully supports TPM 2.0 and Secure Boot. Crucial: Even if Tiny11 allows you to bypass these requirements, do not bypass them. In 2026, Fortnite and COD competitive modes often require these to be enabled in your BIOS to even launch the game. The Final "Best-Case" Strategy OS: Install Tiny11 on the 120GB SSD. Space: Immediately run the powercfg /hibernate off command to save another 30GB. Games: * Install Fortnite on the SSD (it will fit!). You'll get instant loads and perfect textures. Install Call of Duty on the 1TB HDD. It’s too big for the SSD, but since the OS is on a "tiny" and fast SSD, the HDD only has to worry about the game assets, not the background OS tasks. Updates: Tiny11 doesn't always auto-update well. You’ll need to manually check for GPU drivers for your RTX 3070 to ensure you're getting 2026-level optimization. The Verdict: Tiny11 on your 120GB SSD is the only way to make this setup feel like a high-end PC instead of a budget experiment.
