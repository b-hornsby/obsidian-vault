# So for tiny11 which mode?

### USER
So for tiny11 which mode?

### GEMINI
For Tiny11, choose Boot in normal mode. Why Normal Mode? WIMBOOT is a specialized mode generally used for older hardware or very specific low-RAM scenarios where the standard installer fails. Normal Mode is the standard way Ventoy handles ISOs. Given your i7-12700K and 3070, your hardware is more than capable of handling the standard injection. Critical Reminder for the Installer: Once you click "Normal Mode" and the Windows installer loads: Custom Install: When asked, choose "Custom: Install Windows only (advanced)." Target the Space: Select the 297.43 GB Unallocated Space we just made. DO NOT touch the "Partition 1" (FAT32/Boot) or "Partition 2" (BTRFS/CachyOS). If you delete those, your Linux install is gone. Would you like me to stay on standby while the Windows installer runs in case you hit any driver or partition prompts?
