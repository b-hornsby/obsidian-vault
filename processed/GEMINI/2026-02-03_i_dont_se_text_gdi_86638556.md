### GEMINI
if you don't see Text (GDI+), you are almost certainly using OBS on a Mac. GDI+ is a Windows-specific graphics API. Mac users are stuck with Text (FreeType 2), which is objectively garbage. It hasn't been properly updated in years, and as you’ve discovered, it doesn't even allow you to change the outline color—it defaults to a useless grey or stays locked. Stop trying to find a button that doesn't exist. You have three ways to solve this, ranked from "Quick Fix" to "Professional Standard." Solution 1: The "Double Source" Hack (The Quick Fix) Since you can't color the outline, fake it. Create your White Text source. Right-click it -> Copy. Right-click in your Sources -> Paste (Duplicate). Take the bottom copy, go to Filters, and add a Color Correction filter. Turn the Brightness all the way down to -1 (making it pure black). Use your arrow keys to nudge that black text 2 pixels up, down, left, and right. The Verdict: It’s a messy workaround, but it works without leaving OBS. Solution 2: Use the "Stroke" Filter (The Software Fix) If you are on a modern version of OBS (30.0+), there are better filters. Right-click your text -> Filters. Look for Drop Shadow. Set Distance to 0, Blur to 0, and Opacity to 100%. If it’s too thin, you’ll have to stack multiple versions of this filter. The Verdict: Still a compromise, but cleaner than Solution 1. Solution 3: The "Professional" Path (Browser Sources) If you want to stop "playing small" and fighting your tools, stop using OBS's internal text for static or styled labels. Go to Photopea.com (it’s a free web-based Photoshop clone). Type your text, add a Stroke (Black), and a Fill (White). Export as a PNG. Drag that PNG into OBS. The Verdict: This is how actual broadcasters do it. The text is crisp, the outline is perfect, and you don't waste time hunting for missing Windows-only features. The Reality Check You are hitting a wall because you're trying to use a screwdriver to drive a nail. OBS on Mac is notoriously limited in the text department. If you need this text to change frequently (like a "Current Song" or "Latest Sub"), you should be using a Browser Source via StreamElements or a local HTML file. Which is it: Is this text something that stays the same (like your social media handle), or does it need to change while you're live?
