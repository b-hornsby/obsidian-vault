Since you’re on CachyOS (Arch-based Linux), you are in the same boat as Mac users: GDI+ does not exist for you. It is a proprietary Windows API. You are using FreeType 2, which is basic and lacks the styling features you’re looking for. On Linux, you don't wait for the software to give you a button; you use the flexibility of the OS to bypass the limitation. Here is your prioritized plan to get professional white-on-black text. Option 1: The "Composite" Method (Best for Static Text) If this text doesn't change every five minutes (e.g., "Starting Soon" or your Twitter handle), stop using the OBS text source entirely. 1. Open Inkscape or GIMP (both are in the CachyOS/Arch repos). 2. Create your text with a proper stroke/outline. 3. Export as a .png with a transparent background. 4. Add it to OBS as an Image Source. Why: OBS’s internal rendering on Linux is sub-par. External assets will always look sharper and more professional. Option 2: The "Shadow Stack" (The Internal Workaround) If the text must be dynamic (changing often), use the Drop Shadow filter to "simulate" an outline. Add your Text (FreeType 2) source. Set text to White. Right-click the source -> Filters. Add Drop Shadow. Set Distance to 0 and Blur to 0. Set color to Black. If it's too thin, add another Drop Shadow filter and offset it slightly (e.g., 1px right, 1px down). The Flaw: This is computationally "cheap" but can look blocky if you overdo it. Option 3: The "Browser Source" (The Pro Move) This is how you level up on Linux. Linux handles browser rendering (CEF) much better than the old FreeType 2 source. Use a service like StreamElements or a local HTML/CSS file. Use the CSS property -webkit-text-stroke: 2px black;. Add it as a Browser Source in OBS. Why: This gives you pixel-perfect, vector-style outlines that FreeType 2 simply cannot produce. The Strategic Assessment You’re on CachyOS, a high-performance, enthusiast Linux distro. You clearly care about optimization and doing things the "right" way rather than the "easy Windows way." Stop fighting FreeType 2. It is a legacy tool. If you want your stream to reflect the quality of your OS choice, you should move toward Browser Sources for your overlays. They are platform-independent and offer 100% control over typography.
