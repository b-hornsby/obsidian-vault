# Internet Computer ICP: Decentralized Cloud Blockchain

### HUMAN
What is ICP cryptocurrency?

### ASSISTANT
**ICP** is the native cryptocurrency and governance token of the **Internet Computer** (often abbreviated as IC or ICP), a decentralized blockchain platform developed by the DFINITY Foundation.

The Internet Computer is designed to function as a **decentralized alternative to traditional cloud computing** (like AWS or Google Cloud). It aims to host full-stack applications, websites, backend services, and even enterprise systems **entirely on-chain** — directly on the blockchain — without relying on centralized servers. This provides:

- Tamperproof security and resilience against traditional cyber attacks
- Unstoppable operation (censorship-resistant)
- Serverless execution at web speed
- Direct integration with other chains (e.g., Bitcoin support)

The platform runs through a network of independent data centers worldwide that operate specialized node machines, organized into subnets (independent blockchains). Smart contracts on ICP are called **canisters**, which can handle both backend logic and frontend (serving HTTP content directly).

Key features and goals as of 2026 include evolving into a "**self-writing cloud**," where AI tools (like caffeine.ai) allow users to generate and deploy applications via natural language prompts, making development more accessible.

### The ICP Token
ICP serves multiple roles:
- **Fuel** for computation — developers burn ICP tokens to pay for running canisters (cycles are derived from burned ICP).
- **Governance** — holders can stake ICP in the Network Nervous System (NNS) DAO to vote on network decisions.
- Tradable cryptocurrency on exchanges.

As of mid-February 2026, ICP trades around **$2.40 USD**, with a market cap in the low billions, ranking it outside the top 50 cryptocurrencies. It launched in May 2021 with massive hype (reaching highs over $400–700 briefly) but experienced a dramatic decline (>99% from ATH), leading to mixed community sentiment — some view it as underdelivering on early promises, while others see ongoing development in AI integration and decentralization.

The official site is internetcomputer.org, and it's actively developed with tools for builders (SDKs, online IDEs like icp.ninja, and AI-assisted creation).

In short: ICP powers a blockchain that tries to replace centralized cloud infrastructure with a decentralized, sovereign "world computer" — ambitious, technically innovative, but with a volatile price history.
