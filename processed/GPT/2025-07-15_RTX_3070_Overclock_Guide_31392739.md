# RTX 3070 Overclock Guide

### USER
if i were to overclock my gpu (rtx 3070) what would i set that to in msi afterburner?

### ASSISTANT
Overclocking your RTX 3070 with MSI Afterburner can boost performance, but it must be done **gradually and safely**. There’s no universal number, because every card has different limits (called the "silicon lottery"), but I can give you a **safe starting point and method** to dial in your overclock.

### 🔁 **Test for Stability After Each Adjustment**

- Use tools like:
  - **Heaven Benchmark**
  - **3DMark Time Spy**
  - **OCCT or FurMark (with caution)**
  - Play a few GPU-heavy games

If it crashes, artifacts, or temps go above **75–80°C**, dial back core/memory clocks a bit.
