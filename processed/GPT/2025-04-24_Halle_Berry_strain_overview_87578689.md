**Cursor** is an **AI-powered code editor** built on top of **Visual Studio Code (VS Code)**. It's designed to deeply integrate AI assistants (like GPT-4) directly into the coding experience. It helps with things like:

- **Autocompleting code intelligently**
- **Explaining code snippets**
- **Refactoring or generating code**
- **Debugging suggestions**
- **AI pair programming**

It looks and feels like VS Code but comes with deeper AI tools baked in, such as an AI sidebar that can understand your full project and even rewrite files based on your prompts.

### **Install Steps (Linux example):**
1. Go to [https://www.cursor.sh](https://www.cursor.sh)
2. Download the **.deb** or **.AppImage** for Linux
3. In your terminal (Ubuntu):
   ```bash
   sudo dpkg -i cursor.deb
   sudo apt --fix-broken install  # if there are missing dependencies
   ```
4. Launch with:
   ```bash
   cursor
   ```
