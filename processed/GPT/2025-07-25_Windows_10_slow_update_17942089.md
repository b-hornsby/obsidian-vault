## 🧪 Let’s Diagnose in Priority Order

### ✅ Step 1: **Check RAM Usage**
1. Open **Task Manager** (Ctrl + Shift + Esc)
2. Click the **Performance** tab → Look at **Memory**
   - If it's near 90–100%, something may be leaking memory
   - Check the **Details** tab for apps using tons of RAM

### ✅ Step 3: **Run SFC and DISM**
These fix file corruption which often happens after a Windows update.

1. Press **Start**, type `cmd`, right-click → **Run as administrator**
2. Run:
   ```bash
   sfc /scannow
   ```
   After that completes:
   ```bash
   DISM /Online /Cleanup-Image /RestoreHealth
   ```

### ✅ Step 5: **Check Update History & Roll Back**
Sometimes Microsoft pushes a dud update.

1. **Settings → Update & Security → Windows Update**
2. Click **View Update History**
3. Choose **Uninstall Updates**
4. Look for the most recent **“Cumulative Update for Windows 10…”**
5. Right-click → Uninstall

### ✅ Step 7: **Boot into Safe Mode**
If everything still feels laggy:
1. Reboot and **hold Shift while clicking Restart**
2. Navigate: Troubleshoot → Advanced Options → Startup Settings → Restart → Press 4 (Safe Mode)

If the system runs smoothly in Safe Mode, that confirms **driver or background process issue**.

### 🔄 1. **Post-Update Background Tasks**
- **What’s happening:** Windows often performs indexing, disk optimization, Windows Defender scans, or telemetry uploads after an update.
- **Fix:**
  - Wait a few hours or a day if it's right after the update.
  - Check Task Manager (`Ctrl+Shift+Esc`) for processes like `Windows Search Indexer`, `Antimalware Service Executable`, etc.

### 💾 3. **Driver Conflicts or Rollbacks**
- **What’s happening:** Windows Updates sometimes override GPU, audio, or chipset drivers.
- **Fix:**
  - Open **Device Manager** → look for yellow triangles.
  - Reinstall drivers from your manufacturer’s website (especially GPU and chipset).

### 🧹 5. **Storage Space or Disk Fragmentation**
- **What’s happening:** Updates can leave behind large backup files (like `Windows.old`) or temporarily fill your SSD/HDD.
- **Fix:**
  - Run **Disk Cleanup** as admin (`cleanmgr`) → clean system files.
  - Clear out `Windows.old` if you don't need to roll back.
  - Defragment HDDs (don’t defrag SSDs).

### 🛡️ 7. **Security Software Conflicts**
- **What’s happening:** Your antivirus might be misbehaving after the update.
- **Fix:**
  - Temporarily disable 3rd-party antivirus and see if performance improves.
  - Try switching to Windows Defender temporarily.

### 🚨 Bonus: **Too Many Background Apps Autostarting**
- Updates often re-enable junk in startup.

- **Fix:**
  - Press `Ctrl+Shift+Esc` → Startup tab → Disable everything non-essential.
  - Check `Settings → Apps → Startup`.

### 🧾 You’ve landed in your **motherboard’s POST screen** (pre-boot), not Windows yet.

This screen usually appears when:
- BIOS settings were **reset** (power interruption or CMOS battery issue)
- You just did a **hard shutoff**, which triggered a hardware-level fallback
- Or you **pressed the power button too early**, before Windows actually began loading

### 📌 Important Reminder:

To trigger recovery:
- You must let **Windows actually start loading** (look for the **Windows logo or spinner**)
- Then **force shutdown by holding power**
- Do this **3 times**
- On the **4th boot**, it should auto-enter **recovery mode**

## 🧠 What These Processes Are Doing

### 🔍 **Windows Search Indexer (SearchIndexer.exe)**
- **Purpose:** Scans and indexes all your files so search is instant.
- **Post-update behavior:** Re-indexing everything after a system update or file structure change = high CPU or disk usage.

### 🛡️ **Antimalware Service Executable (MsMpEng.exe)**
- **Purpose:** It’s part of Windows Defender — scans for malware.
- **Post-update behavior:** Often kicks in hard after updates, doing a **full system scan** in the background.

### 2. **Temporarily Pause Windows Search Indexing**
If your disk or CPU is pegged by `SearchIndexer.exe`:

#### 🧯 Stop it temporarily:
1. Press `Win + R`, type `services.msc`
2. Find **Windows Search**
3. Right-click → **Stop**

#### 🛠 Optional: Disable it (if you don't use Windows Search much)
1. Right-click again → **Properties**
2. Set **Startup type** to **Disabled**

⚠️ If you do this, search in File Explorer and Start Menu will be slower.

### 4. **Switch to a Custom Power Plan**
Sometimes Windows updates reset it back to **Balanced**.

#### ✅ Set it to High Performance:
1. `Control Panel → Power Options`
2. Choose **High Performance** (or create a custom one).

### 6. **Check for Ongoing Scans**
Sometimes Defender is still scanning:

1. Go to **Windows Security → Virus & Threat Protection**
2. Look under **Current threats** → If it says "Scanning," that’s your culprit.

You can pause or schedule scans during idle time.
