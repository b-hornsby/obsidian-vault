### ASSISTANT
Here's a streamlined, intuitive breakdown of what you need to know for the **CompTIA A+ (220-1101 & 220-1102)** based on the MedCerts program. This guide focuses on key concepts, easy-to-remember explanations, and practical application.

## **1️⃣ Hardware & Peripherals (Core 1)**
### **🖥️ Computer Components**
- **CPU** (Brain of the computer) → Key specs: Clock speed (GHz), Cores, Threads, Cache.
- **RAM** (Short-term memory) → DDR4/DDR5, Speeds (MHz), Dual-channel improves performance.
- **Storage** (Long-term memory)  
  - **HDD** (Slow, cheap, spinning disk)  
  - **SSD** (Fast, uses flash storage; NVMe is even faster!)  
  - **Hybrid (SSHD)** = Combo of both.
- **Power Supply (PSU)** → Converts AC to DC; watch **wattage & efficiency ratings** (80+ Bronze, Gold, etc.).
- **Motherboard (MoBo)** → Determines **compatibility** (CPU socket, RAM type, expansion slots).

### **🎮 Ports & Cables**
- **USB (A, B, C, Mini, Micro)** → USB 3.0+ = **Blue**, USB-C = **Reversible**
- **HDMI vs. DisplayPort** → HDMI (common), DisplayPort (higher refresh rate)
- **RJ45 (Ethernet) vs. RJ11 (Phone Line)**
- **SATA vs. NVMe (Storage connections)**

### **🖨️ Printers**
- **Laser** (Toner-based, fast, high-volume)
- **Inkjet** (Liquid ink, good for colors)
- **Thermal** (Receipts, uses heat-sensitive paper)
- **Impact (Dot Matrix)** (Old-school, noisy, carbon copies)
- **Common Fixes** → Driver updates, paper jams, connectivity checks.

## **3️⃣ Mobile & Cloud Computing (Core 1)**
### **📱 Mobile Device Support**
- **iOS vs. Android** (Different update/security policies)
- **Common Fixes** → Restart, clear cache, update OS/apps.

### **☁️ Cloud Computing**
- **SaaS (Software as a Service)** → Google Docs, Office 365
- **IaaS (Infrastructure as a Service)** → AWS, Azure
- **PaaS (Platform as a Service)** → Heroku, Google App Engine
- **Virtualization** → Running multiple OS instances on one machine.

## **5️⃣ Security (Core 2)**
### **🔑 Authentication & Access Control**
- **MFA (Multi-Factor Authentication)** → Password + SMS/App verification.
- **Biometrics** → Fingerprint, Face ID.
- **Access Control** → **Least Privilege Principle** (Users only get the access they need).

### **🛡️ Malware & Threats**
- **Virus** → Self-replicating, attaches to files.
- **Worm** → Spreads on its own, no user action needed.
- **Trojan** → Disguised as legit software.
- **Ransomware** → Encrypts files, demands payment.
- **Phishing** → Fake emails/websites trick users.
- **Spyware** → Tracks keystrokes & activity.

### **💾 Data Protection**
- **Encryption (AES-256 best for security)**
- **BitLocker (Windows), FileVault (Mac)** → Encrypts drives.
- **Backups** → 3-2-1 Rule (3 copies, 2 media, 1 off-site).

## **✅ Final Exam Tips**
- **Know troubleshooting steps cold.**
- **Memorize port numbers (FTP 21, SSH 22, HTTP 80, HTTPS 443, etc.).**
- **Understand networking basics (IP, MAC, Subnetting).**
- **Learn security best practices (passwords, MFA, encryption).**
- **Practice with real hardware/software!** (Virtual machines, hands-on labs)
- **Do lots of practice tests.** (Simulate real exam conditions!)
