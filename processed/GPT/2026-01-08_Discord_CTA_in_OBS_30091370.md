# Discord CTA in OBS

### ASSISTANT
If the goal is **a clean, effective “Join my Discord” call-to-action in OBS**, you have three realistic implementation paths. I’ll give you the practical breakdown and then the exact steps for each.

## Option 2 – **Animated CTA (More Engaging, Still Simple)**
Best for attention without being obnoxious.

### Steps
1. Create an animated banner:
   - After Effects, Canva animation, or Kapwing
   - Export as **MP4 (with transparency if supported)** or **WebM**

2. In OBS:
   - `Sources` → `+` → **Media Source**
   - Add your video
   - Enable:
     - **Loop**
     - **Restart playback when source becomes active**

3. Position it where it won’t cover gameplay/UI.

### Pro Tip
Short loop. 2–4 seconds. Anything longer becomes visual noise.

## Option 4 – **Chat Command + On-Screen Prompt (High Conversion)**
This is what actually converts, not just pretty overlays.

- Set up a bot command: `!discord`
- Add a small on-screen CTA:  
  *“Type !discord in chat to join”*

This does two things:
1. Trains behavior
2. Reduces friction (no link typing)
