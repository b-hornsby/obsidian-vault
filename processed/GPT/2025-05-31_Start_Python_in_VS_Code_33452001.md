# Start Python in VS Code

### ASSISTANT
Starting a Python file in VS Code is super straightforward! Here’s a quick step-by-step to get you going:

### 1. Open VS Code  
- Launch **Visual Studio Code**.

### 2. Open a folder or workspace (optional but recommended)  
- It’s good to open a folder where you want to keep your Python files.  
- Click **File > Open Folder...** and select or create a folder.

### 3. Create a new Python file  
- Click on the **Explorer** icon on the left sidebar (looks like two files).  
- Click the **New File** icon (a piece of paper with a plus sign) or press `Ctrl + N` to create a new file.  
- Name the file ending with `.py`, for example, `my_script.py`.

### 4. Write your Python code  
- Type your Python code in the editor window. For example:
```python
print("Hello, world!")
```

### 5. Run your Python file  
There are a couple of ways to run Python in VS Code:

- **Using the Run button:**  
  If you have the Python extension installed, you’ll see a green **Run** button at the top right of the editor. Click it to run your script in the terminal.

- **Using the terminal:**  
  Open the terminal inside VS Code by pressing `` Ctrl + ` `` (backtick) or via **View > Terminal**.  
  Then type:
  ```
  python my_script.py
  ```
  and press Enter. (Use `python3` if your system differentiates Python 2 and 3.)
