# Coinbase Wallet XRP Support

### ASSISTANT
Yes, several **cold storage wallets** support **XRP**, but **Phantom Wallet does not**, since it's primarily designed for the **Solana blockchain** and does not support the **XRP Ledger (XRPL).**  

If you want to store XRP securely in **cold storage**, consider these options:  

### **Hardware Wallets (Best Cold Storage Options)**
1. **Ledger Nano X / Ledger Nano S Plus** – Supports XRP through Ledger Live and third-party apps.  
2. **Trezor (via third-party apps)** – XRP is not natively supported, but you can manage it through third-party interfaces like Exodus.  
3. **Ellipal Titan** – A completely air-gapped cold wallet that supports XRP.
