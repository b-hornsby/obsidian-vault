### **Step 3: Install a Wayland-Compatible Login Manager (Optional but Recommended)**

If you're using KDE's **SDDM**, make sure Wayland support is enabled:

```bash
sudo nano /etc/sddm.conf
```

```
WaylandSession=hyprland
```

```bash
sudo dnf install gdm
```

## **Imagine Your Linux Setup Like Building a Custom Gaming PC**

Each layer of Linux is like a component in your build. You choose what parts to use depending on how much control or flash you want.

### **Layer 2: The Power Supply (Display Server)**
This makes your screen work. There are two types:

- **X11** = older, stable, but aging (used by many DEs like XFCE, older KDE)
- **Wayland** = newer, faster, supports modern effects (used by Hyprland, new KDE, GNOME)

Think of **Wayland** as a modular PSU—more efficient, sleeker, but not every old part (app) fits without a little tweaking.

### **Layer 4: Your Components (Apps + Tools)**

With Hyprland, you *pick and install everything yourself*:
- Terminal = `kitty`, `alacritty`
- Bar = `waybar`

Each tool is like adding a GPU, RAM, or RGB controller—you pick the exact model and brand.

## **Putting It All Together: Your Final Setup**

When you boot Nobara + Hyprland, here’s what’s happening:

1. **Nobara OS** boots (Layer 1)

Editing the **Hyprland config file** is straightforward once you know where it’s located and what kind of settings you can modify.

### **Steps to Edit the Hyprland Config File**

1. **Locate the Configuration File**  
   The main configuration file is located in:  
   `~/.config/hypr/hyprland.conf`  
   If it doesn't exist yet, you can copy the default template:

   ```bash
   cp /etc/xdg/hypr/hyprland.conf ~/.config/hypr/
   ```

2. **Open the File with a Text Editor**  
   You can use any text editor, like **nano** or **vim**, to edit this file. If you're unfamiliar with vim, **nano** is simpler to use. Open it with:

   ```bash
   nano ~/.config/hypr/hyprland.conf
   ```

3. **What to Edit Inside the Config File**  
   The config file is **well-commented**, meaning there are notes in the file that explain each section. Let’s break down some key parts of the file you’ll want to edit:

### **Key Sections in the Config File**

#### **1. Window Management Settings**
- **Tiling, Floating, and Gaps**: 
  Hyprland uses a tiling layout by default, but you can customize window behavior (e.g., gaps between windows).
  
  ```bash
  window_gap = 10 # Adjusts the gap between windows
  ```

- **Window Rules**:  
  You can set rules for certain applications, like floating windows or specific sizes.

  ```bash
  windowrule = "float: *Spotify*"
  ```

#### **2. Keybindings**  
In this section, you define **keyboard shortcuts** for actions (e.g., opening a terminal, launching apps, or switching workspaces).

- Example of keybinding for opening a terminal with `Mod+Enter`:

  ```bash
  bind = SUPER+Return, exec, kitty
  ```

  You can add as many keybindings as you like—just follow the pattern:  
  `bind = [key], [command]`

#### **3. Screen/Monitor Settings**  
If you have multiple monitors, you can configure how they behave (e.g., positioning and scaling).

- Example of setting the monitor layout:

  ```bash
  monitor=HDMI-A-1,1920x1080@60
  monitor=DP-1,1920x1080@60, primary
  ```

#### **4. Appearance & Effects**  
This is where you can change the **look and feel** of Hyprland (e.g., animations, borders, etc.).

- Example for customizing border colors and effects:

  ```bash
  border_width = 3 # Set the width of window borders
  active_border_color = #FF00FF # Active window border color (purple)
  inactive_border_color = #888888 # Inactive window border color (gray)
  ```

#### **5. Startup Programs (Auto-run)**  
You can add programs to **start automatically** when you log in.

- Example for auto-starting Waybar, a wallpaper, and Dunst (notifications):

  ```bash
  exec-once = waybar &
  exec-once = swww init && swww img ~/Pictures/wallpapers/my_wallpaper.jpg &
  exec-once = dunst &
  ```

#### **6. Workspaces and Layouts**  
Hyprland lets you define workspaces and what happens when you switch between them. You can even set different layouts (like floating or tiling) per workspace.

- Example for setting workspace layouts:

  ```bash
  workspace_layout = "tiling"
  workspace_layout = "floating" # For a specific workspace (e.g., a web browser)
  ```

### **Example Config: Basic Hyprland Config File**

Here’s a minimal example of what the **~/.config/hypr/hyprland.conf** might look like:

```bash
# Window settings
window_gap = 10
border_width = 3
active_border_color = #FF00FF
inactive_border_color = #888888

# Autostart programs
exec-once = waybar &
exec-once = swww init && swww img ~/Pictures/wallpapers/my_wallpaper.jpg &

```
