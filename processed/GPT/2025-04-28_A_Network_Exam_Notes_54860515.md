### 🔹 Network Components & Communication
- **Router**: Directs data between networks based on IP addresses.
- **Switch**: Connects devices within a network, forwarding data based on MAC addresses.
- **Access Point (AP)**: Provides wireless network access to clients.
- **Server/Client**: Server provides resources; client requests them.
- **Purpose**: Ensure devices communicate efficiently, reliably, and securely.

### 🔹 Network Storage Technologies
- **NAS (Network Attached Storage)**: Centralized file storage accessible like a network folder; easy to set up.
- **SAN (Storage Area Network)**: High-speed network dedicated to data transfer between storage devices and servers; complex setup.
- **Cloud Storage**: Off-site storage accessed over the Internet (e.g., Dropbox, iCloud).

### 🔹 Routing and Traffic Forwarding
- **Routers** use routing tables to choose best paths.
- **Dynamic Routing Protocols**: Automatically update routes (OSPF, BGP, RIP).
- **Static Routing**: Manual route entries.

### 🔹 Switch Interfaces
- **VLANs**: Virtual networks inside a switch; logically separate groups of devices.
- **Trunking (802.1Q)**: Allows multiple VLANs to travel over one link between switches.
- **Port Security**: Limits devices connecting to switch ports (MAC address filtering).

### 🔹 Network Documentation
- **Physical Diagrams**: Layout of hardware and cabling.
- **Logical Diagrams**: IP addresses, VLANs, routing.
- **Change Management**: Process of recording and approving network changes.

### 🔹 Network Discovery
- **Ping Sweeps**: Check which devices are live.
- **Port Scanning (NMAP)**: Find open services and devices.
- **SNMP Polls**: Request device info (e.g., interfaces up/down).

### 🔹 Data States
- **At Rest**: Stored data (hard drive, SSD).
- **In Transit**: Data moving across networks.
- **In Use**: Data actively processed (RAM, CPU).

### 🔹 Troubleshooting Concepts
- **Identify Problem → Form Hypothesis → Test → Plan Fix → Implement → Verify → Document**.
- Always **start simple** (Layer 1: cables, power) before moving up (Layer 2: switching, Layer 3: routing).

# 📚 Quick Notes – Network+ 009 Introduction

### Wireless Appliances
- **Access Points (APs)**: Provide Wi-Fi access.
- **Wireless Controllers**: Manage multiple APs centrally.
- **Wireless bridges**: Connect two wired networks **wirelessly**.
- **Functionality**: Make mobility and flexible connections possible.

### Cloud Concepts
- **Cloud types**: Public (everyone), Private (single organization), Hybrid (mix of both).
- **Components**:
  - **IaaS** (Infrastructure as a Service): Rent servers (e.g., AWS EC2)
  - **PaaS** (Platform as a Service): Rent environments to develop apps
  - **SaaS** (Software as a Service): Rent apps (e.g., Gmail, Office 365)

### Address Translation (NAT & PAT)
- **NAT (Network Address Translation)**: Converts **private IPs** into **public IPs**.
- **PAT (Port Address Translation)**: Uses **ports** to map multiple private IPs to one public IP (common in home routers).

### Physical Installations
- **Environmental factors**:
  - Temperature
  - Humidity
  - Airflow
- **Power considerations**:
  - UPS (Uninterruptible Power Supply)
  - Redundant power supplies
  - Proper grounding

### Network Monitoring
- **Categories**:
  - **SNMP** (Simple Network Management Protocol) for device stats
  - **Syslog** for logging events
  - **SIEM** (Security Information and Event Management) for security logs

### Remote Access
- **Connection methods**:
  - VPN (Virtual Private Network)
  - SSH (Secure Shell)
  - RDP (Remote Desktop Protocol)

### Securing Data
- **Common methods**:
  - **Encryption** (both at rest and in transit)
  - **Authentication** (passwords, MFA)
  - **Access Control Lists** (ACLs)

# 🎯 Remember:
- Think about **layers** (physical vs logical).
- Always **document** what you do.
- Troubleshooting is **systematic**, not random guessing.
