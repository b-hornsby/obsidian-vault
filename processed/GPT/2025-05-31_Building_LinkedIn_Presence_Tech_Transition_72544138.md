## 🛠️ 2. Execution Steps (Document Each!)

### 📸 Step 1: Unboxing and Initial Assessment
- Power it on. What happens?
- BIOS accessible?
- Any obvious damage, noises, missing keys?
- Take photos of:
  - The laptop as-is
  - BIOS screen
  - Startup errors (if any)

### 🧪 Step 2: Diagnostic Work
Run hardware checks using a **bootable USB**:
- [Hiren’s Boot CD PE](https://www.hirensbootcd.org/)
- [MemTest86](https://www.memtest86.com/) for RAM
- [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) for HDD/SSD health
- Ubuntu Live USB to test functionality without installing anything

Document what passed/failed. Screenshot any SMART errors, memory issues, etc.

### 🧼 Step 3: Physical Cleanup & Inspection
- Disassemble the bottom case
- Clean fans, internals
- Reseat RAM, drive, battery
- Check thermal paste if you're confident

Take photos of:
- Dust cleanup
- Before/after internals
- Anything broken (ribbon cables, cracked hinges, bloated batteries)

### 🔧 Step 4: Attempt Repairs or Upgrades
- Replace thermal paste? Upgrade RAM? Swap in SSD?
- Replace keyboard or trackpad?
- Install an OS (Ubuntu is fast + friendly)
- Create a “Refurb Checklist” like a tech depot would use

Log all changes and test results:
- Boot times before/after
- Temperature readings before/
