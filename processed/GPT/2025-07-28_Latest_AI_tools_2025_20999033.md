## 🧠 How Continue.dev Works with Local Models

Think of **Continue.dev** as the *user interface and workflow layer* inside VS Code — it doesn't run the model itself. It just connects to **a backend LLM provider**, which **can be local**.

So here’s the pipeline:

```
[ You in VS Code ] 
       ⇅
[ Continue.dev ]
       ⇅
[ Your Local Model (Ollama, llama.cpp, etc.) ]
```

### 2. **llama.cpp (More Advanced / Lightweight)**
- If you use `llama.cpp` to run `.gguf` models manually, you need to expose it as a **REST API**
- Tools like **llama-cpp-python** or **text-generation-webui** can expose a local endpoint (`http://localhost:8000`) that Continue can talk to

You'd then use a **custom provider** in Continue like this:

```json
{
  "models": [
    {
      "title": "LLaMA Local",
      "provider": "openai",
      "apiBase": "http://localhost:8000/v1",
      "model": "llama"
    }
  ]
}
```

> 🔧 Note: The `"provider": "openai"` just means it follows the OpenAI API **format**, not that it's OpenAI's actual service. You’re still fully local.
