# Modded Switch for Mig V2

### ASSISTANT
Yes, you need a modded Nintendo Switch to use **Mig Switch V2**, as it relies on custom firmware (CFW) and tools that are typically only possible on consoles that can run homebrew. Here's a breakdown:

### **Key Points:**
1. **Unpatched Switch Units Only:**
   - Not all Switch consoles can be modded. Only **"unpatched"** first-generation models can run custom firmware like Atmosphere, which Mig Switch V2 requires. 
   - Check your Switch's serial number [here](https://ismyswitchpatched.com/) to see if it is unpatched.

2. **Modded Hardware for Patched Units:**
   - If your Switch is a patched model or an OLED version, you would need a hardware mod like **HWFLY or SX Core** to bypass security and enable homebrew.

3. **CFW Installation:**
   - You'll need to install a compatible custom firmware (e.g., Atmosphere or similar) to use tools like Mig Switch V2 for emulation, hacking, or other custom functionalities.
