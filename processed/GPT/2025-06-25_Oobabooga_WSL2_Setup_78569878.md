### 🔁 **Step-by-Step: Installing Oobabooga (text-generation-webui) the Right Way in WSL2**

#### 🧼 0. Start Fresh (you’ve already done this — perfect)
- Make sure your WSL2 Ubuntu environment is clean.
- Update it:
  ```bash
  sudo apt update && sudo apt upgrade -y
  ```

#### 📦 1. Install Required Dependencies
```bash
sudo apt install git wget curl python3 python3-venv python3-pip -y
```

#### 📁 2. Clone Oobabooga Repo
```bash
git clone https://github.com/oobabooga/text-generation-webui.git
cd text-generation-webui
```

#### 🧪 3. Set Up Python Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate
```

#### 🧰 4. Install Python Requirements
```bash
pip install -r requirements.txt
```

#### 🧠 5. Download Your Model
You can use the built-in downloader:
```bash
python download-model.py TheBloke/Nous-Hermes-2-Mistral-7B-DPO-GGUF
```
Or manually drop `.gguf` models into the `models/` folder.

#### 🚀 6. Run the Web UI
```bash
python server.py --model models/YourModelFolder
```

Or if using GGUF:
```bash
python server.py --model models/YourModelFolder --loader llama.cpp
```

### 💡 Pro Tips

- **Use Windows Terminal** to launch WSL2 for better compatibility.
- Store your **models in `/mnt/d/LLMs/`** or another large drive if you want to preserve space.
- If you want image generation or extensions later, this structure will be easier to work with.
