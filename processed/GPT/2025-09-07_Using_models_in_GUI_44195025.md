### **How the new Ollama GUI handles models**
1. You **don’t pre-download models manually**.  
2. You **select a model from the dropdown in the chat interface**.  
3. When you type a prompt and hit **Enter**, Ollama automatically:
   - Downloads the model if it’s not already on your system.
   - Loads it and then responds to your prompt.  

So the “download” happens **on-demand** when you actually start a chat with that model. That’s why you don’t see a manual download option anywhere.

### **For VS Code / CLI usage**
- You can still use your models in VS Code, but they **must exist in the new Ollama installation path**.  
- If it’s an official model: just run `ollama run <model-name>` in the terminal, and it will automatically download the model the first time you use it.  

- If it’s a **custom model** (from a `.gguf` or other local file):
  1. You need to **import it manually into Ollama** (check for “Import Model” in the GUI).  
  2. Then you can use it in VS Code exactly like before.
