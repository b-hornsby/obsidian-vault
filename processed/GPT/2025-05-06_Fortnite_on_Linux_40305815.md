# Fortnite on Linux

### ASSISTANT
As of now, **it's very unlikely** that Fortnite will get **native Linux support**, and here’s why:

### 1. **Epic Games' Priorities**
- **Epic’s CEO Tim Sweeney** has publicly stated that Linux isn’t a priority for them, especially for Fortnite.
- Fortnite is a massive commercial product, and **Linux represents a tiny fraction of the gaming market** (under 2%).

### 2. **Anti-Cheat Roadblocks**
- Fortnite uses **Easy Anti-Cheat (EAC)**, owned by Epic Games.
- While EAC **technically supports Linux and Proton**, Epic has **not enabled it for Fortnite**.
- Enabling EAC on Linux requires **developer effort and testing**, which Epic has not invested in.

### 3. **Business Strategy**
- Fortnite is used to promote **Windows and the Epic Games Store**, so there’s little incentive for Epic to invest in another platform.
- Epic is also engaged in business rivalries with companies like Apple and Steam, so **Linux gaming just isn’t part of their strategy**.

### 4. **Unreal Engine ≠ Fortnite**
- While Epic does support Linux builds for **Unreal Engine**, that doesn't mean **Fortnite the game** will follow suit.
---
### Bottom Line:
Unless there's a **massive shift in Linux gaming market share** or **Epic changes its priorities**, **native Linux support for Fortnite is extremely unlikely**.

### ASSISTANT
You **can’t natively run Fortnite on Linux** in a fully supported way—**especially not with anti-cheat enabled in Battle Royale mode**—but there are workarounds, with major limitations:

### 1. **Using Wine/Proton (not recommended for Battle Royale)**
- **Wine/Proton** can technically run the Fortnite launcher.
- **Battle Royale mode won’t work** due to **Easy Anti-Cheat (EAC)** not being supported in Linux for Fortnite. EAC support on Linux is up to developers to enable, and Epic Games hasn't done that for Fortnite.
- You **can only play Creative mode** (without anti-cheat), and even that is hit-or-miss.

### 2. **Using a Windows VM with GPU passthrough (advanced)**
- You set up **QEMU/KVM with GPU passthrough** to run a Windows VM inside Linux.
- Fortnite runs like it's on a native Windows machine, including Battle Royale.
- Requires **a second GPU** and technical knowledge (IOMMU groups, VFIO).

### 3. **Using Cloud Gaming**
- Services like **Xbox Cloud Gaming** or **NVIDIA GeForce NOW** support Fortnite.
- You can stream Fortnite via a browser on Linux without worrying about anti-cheat or compatibility.

### TL;DR:
- **Battle Royale?** Not on native Linux.
- **Creative mode?** Maybe, with Wine, but unstable.
- **Best options:** Use **cloud gaming** or run Windows in a **GPU-passthrough VM**.
