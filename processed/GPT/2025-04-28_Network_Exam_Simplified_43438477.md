## 1. **Networking Basics**

- **Network** = 2+ devices communicating.
- **LAN** = Local network (like inside a house).
- **WAN** = Big network (like the internet).
- **Switch** = Smart device that connects computers on a LAN.
- **Router** = Connects different networks together (like your home to the internet).
- **Firewall** = Blocks bad traffic.
- **Server** = Provides stuff (files, web pages, etc.).
- **Client** = Uses stuff from a server.

## 3. **IP Addressing**

- **IP address** = your device’s mailing address.
- **IPv4** = Old style (example: `192.168.1.1`)
- **IPv6** = New style (example: `fe80::1`), longer, for more devices.

- **Private IPs** (for home/internal networks):
  - `10.x.x.x`
  - `172.16.x.x – 172.31.x.x`
  - `192.168.x.x`

- **Subnet Mask** = Tells which part of the IP is the network vs host (ex: `255.255.255.0`).

- **Default Gateway** = Router IP address (where traffic leaves your network).

## 5. **Network Topologies**

- **Star** = Everything connects to a central switch/router.
- **Mesh** = Devices are all connected to each other (good for redundancy).
- **Bus** = One cable, all devices connect (old school).

- **UTP** = Unshielded twisted pair (normal Ethernet cable).

## 9. **Network Security**

- **VPN** = Secure tunnel across public internet.
- **TLS/SSL** = Encryption for websites (HTTPS).
- **Firewall** = Controls traffic.
- **IDS** = Intrusion Detection System (detects attacks).
- **IPS** = Intrusion Prevention System (detects + blocks).

**Authentication Methods:**
- **MFA** = Multi-Factor Authentication (password + text message code).
- **AAA** = Authentication, Authorization, Accounting.

## 11. **Cloud & Virtualization Basics**

- **Cloud** = Using someone else's servers.
- **SaaS** = Software as a service (Google Docs).
- **PaaS** = Platform as a service (for developers).
- **IaaS** = Infrastructure as a service (renting servers).
- **Virtualization** = One computer running multiple "virtual" computers.

# **Quick Memorization Tips**

- Know your **port numbers** (20/21 FTP, 22 SSH, 80 HTTP, 443 HTTPS).
- Know the difference between **Switch** (LAN) and **Router** (connects networks).
- Know common **cables** (Cat5e vs Cat6).
- Know basic **wireless** standards (802.11a/b/g/n/ac/ax).
- Understand **troubleshooting order**.
- Recognize **IP address ranges** for private IPs.

**If you study everything above and truly understand it**,  
you have about a **90% chance** of passing Network+ easily.

# **Network+ Micro Cram Sheet — 5 Minute Morning Review**

### **IP Basics**
- **IPv4** = `192.168.x.x`

### **Wi-Fi (Wireless Standards)**
- **2.4 GHz** = Farther, slower (b/g/n).
- **5 GHz** = Faster, shorter range (a/n/ac/ax).
- **802.11n** = Dual-band.
- **802.11ax** = Wi-Fi 6 (fastest, newest).

### **Network Topologies**

- `ifconfig` = Show Linux/Mac IP info.
- `nslookup` = Check DNS.
- `netstat` = Active connections.
- `nmap` = Port scanning.
