# XRP Wallet Options

### ASSISTANT
Several wallets support storing XRP. Here are some of the best options:

### **Software Wallets (Hot Wallets)**
1. **Xumm** – A non-custodial XRP wallet with advanced features like signing transactions and DeFi integration.
2. **Ledger Live (with Ledger Hardware Wallet)** – While not a standalone software wallet, Ledger Live allows you to manage XRP securely when paired with a Ledger hardware device.
3. **Trust Wallet** – A multi-crypto wallet that supports XRP and offers decentralized app (dApp) access.
4. **Exodus** – A user-friendly wallet with a built-in exchange and support for multiple cryptocurrencies, including XRP.
5. **Atomic Wallet** – A multi-currency wallet with built-in staking and exchange features.

### **Hardware Wallets (Cold Storage)**
1. **Ledger Nano S / Ledger Nano X** – One of the most secure options for long-term XRP storage.
2. **Trezor (via third-party integrations)** – Trezor does not natively support XRP, but you can use third-party solutions like Exodus to manage it.

### **Web Wallets**
1. **GateHub** – A Ripple-focused wallet that also functions as an exchange.
2. **Uphold** – A multi-asset wallet and exchange that supports XRP storage and trading.
