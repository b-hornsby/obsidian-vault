# AST grep overview

### ASSISTANT
Here’s the brutally honest, no-fluff breakdown.

## **What is AST-grep?**
AST-grep is a **code search and code transformation tool** that works on the **AST (Abstract Syntax Tree)** level instead of plain text.

Think “supercharged grep.”  
Instead of searching strings like `function(` or `userId`, it searches for **code patterns** like:

- “any function call with two arguments”
- “any if-statement checking `x == null`”
- “any React component with useEffect missing dependencies”
- “any Python function missing a return type”
- “rename every variable named `foo` to `bar` *but only if it’s a local variable*”

It understands the structure of your code.  
It’s basically **Semgrep but faster**, **tree-sitter powered**, and insanely flexible.

## **Can you use AST-grep in Windsurf?**
Short answer: **Yes. Absolutely.**
