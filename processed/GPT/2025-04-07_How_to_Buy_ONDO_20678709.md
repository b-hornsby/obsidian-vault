**MetaMask cannot directly hold XRP** (Ripple) because **XRP is not an ERC-20 token** and doesn’t run on the Ethereum blockchain — it runs on its **own XRP Ledger**.

### If you *really* want to use XRP with MetaMask:

You can use **Wrapped XRP (wXRP)** — it’s an ERC-20 token that represents XRP on the Ethereum blockchain.

- You’ll need to **wrap XRP using a bridge** (like Multichain or Portal).
- Once you have **wXRP**, you can add the custom token to MetaMask using the contract address.
- But keep in mind: **wXRP ≠ native XRP**. You’d have to unwrap it to get real XRP again.

### TL;DR:

- **MetaMask can't hold real XRP natively.**
- You *can* hold **Wrapped XRP (ERC-20)** if you're on Ethereum.
- For real XRP, use **Xumm, Trust Wallet, or Ledger**.
