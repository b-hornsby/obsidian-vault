### **Daily Actions:**

**Day 1 (Today): Setup Database**
- Install SQLite3 if you haven’t already. (It's built into Python by default.)
- Create a SQLite database (`murad_tracker.db`).
- Create a table for coin price history:
  ```sql
  CREATE TABLE prices (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
      coin_name TEXT,
      price REAL,
      market_cap REAL
  );
  ```
- Save this in a `.sql` file or create it via Python (`sqlite3` module).

**Day 2: Modify Fetching Script to Save into Database**
- After you fetch price and market cap for each coin, insert the results into the database like:
  ```python
  import sqlite3
  
  conn = sqlite3.connect('murad_tracker.db')
  c = conn.cursor()
  
  c.execute('INSERT INTO prices (coin_name, price, market_cap) VALUES (?, ?, ?)',
            (coin_name, price, market_cap))
  
  conn.commit()
  conn.close()
  ```
- **Key:**  
  Every API fetch now **saves** data, doesn't just print it.
