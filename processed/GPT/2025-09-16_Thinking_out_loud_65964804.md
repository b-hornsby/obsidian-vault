## 🚀 Step 3 — Add AI summary
- **No-code:** Zapier/Make both have “AI by OpenAI” or webhooks. You can send `Notes/Description` to GPT (or even your local LLM via API if you want to flex).  
- **Code:**  
  ```python
  from openai import OpenAI
  client = OpenAI()

  def summarize_task(description):
      response = client.chat.completions.create(
          model="gpt-4o-mini",  # or your local model
          messages=[{"role": "system", "content": "Summarize tasks clearly and briefly."},
                    {"role": "user", "content": description}]
      )
      return response.choices[0].message.content.strip()
  ```
