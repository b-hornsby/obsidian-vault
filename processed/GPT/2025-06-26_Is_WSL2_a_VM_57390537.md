# Is WSL2 a VM

### USER
Is wsl2 considered a vm?

### ASSISTANT
Yes, **WSL2 (Windows Subsystem for Linux 2)** *is* considered a **lightweight virtual machine (VM)**.

Here’s the breakdown:

### ✅ Summary
WSL2 *is* a **virtual machine** — but it's **optimized**, **headless**, and **integrated** tightly with Windows. Think of it as a “developer-friendly VM” that skips a lot of the traditional VM overhead.
