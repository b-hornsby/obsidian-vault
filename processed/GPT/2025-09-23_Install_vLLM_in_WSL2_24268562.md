### 2️⃣ Download / point to the model
vLLM can load models from Hugging Face directly. For Mistral 7B 4-bit:

```bash
python -m vllm.entrypoints.text_generate \
  --model "mistralai/Mistral-7B-Instruct-v0" \
  --dtype "float16" \
  --load-in-4bit True \
  --prompt "Hello! Test 4-bit Mistral 7B." \
  --num-outputs 1
```

**Notes:**
- `--dtype "float16"` + `--load-in-4bit True` ensures it runs efficiently in VRAM-limited setups.  
- If you want really low VRAM usage, `--max-seq-len` can be set to limit input length.

### 4️⃣ Test with a small prompt first
Keep prompts short at first to ensure the model loads and generates successfully. If it crashes on loading, you might need to:
- Use `--num-gpu 1` to specify the GPU.
- Reduce `--max-seq-len`.
- Ensure your `bitsandbytes` install is compatible (sometimes `pip install --force-reinstall bitsandbytes` helps).

### **1️⃣ Make a test script**
In your project folder (`~/vllm_project`), create a file called `test_mistral.py`:

```python
from vllm import LLM, SamplingParams

# Model ID on Hugging Face
model_name = "mistralai/Mistral-7B-Instruct-v0"

# Load model with 4-bit quantization
llm = LLM(
    model=model_name,
    dtype="float16",
    quantization="bitsandbytes"
)

# Define how we want it to generate
sampling_params = SamplingParams(
    temperature=0.7,
    top_p=0.95,
    max_tokens=128,
)

# Prompt
prompt = "Hello! Test 4-bit Mistral 7B. How are you today?"

# Run generation
outputs = llm.generate([prompt], sampling_params)

# Print results
for output in outputs:
    print("Prompt:", output.prompt)
    print("Response:", output.outputs[0].text)
```

### **3️⃣ Notes**
- `quantization="bitsandbytes"` tells vLLM to load the model in **4-bit mode**.  
- If you run into CUDA/VRAM errors, we can tweak it with extra flags (`max_model_len`, etc.).
