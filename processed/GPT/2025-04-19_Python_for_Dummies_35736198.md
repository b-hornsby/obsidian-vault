### `==` (double equals)

👉 **This is for *checking* a value.**

You're asking: “Is this equal to that?”

```python
if name == "Melon":
    print("You're the chosen fruit.")
```
Means: “If the variable `name` *equals* 'Melon', then do the thing.”

So:
- Use `=` when **setting** a value.
- Use `==` when **comparing** values.
