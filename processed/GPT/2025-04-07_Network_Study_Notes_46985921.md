### **2. Wireless Appliances**

- **WAPs (Wireless Access Points):** Extend wireless range and provide Wi-Fi.
- **Wireless Controllers:** Manage multiple WAPs centrally (like a boss).
- **SOHO Routers:** All-in-one home devices — router, switch, WAP, firewall.

**Wireless Standards:**
- 802.11a/b/g/n/ac/ax — Each newer version = faster, better range, less interference.

### **4. Cloud Concepts**

- **IaaS:** Infrastructure — VMs, storage (like AWS EC2).
- **PaaS:** Platform — app dev environments (like Google App Engine).
- **SaaS:** Software — apps delivered over the web (like Gmail or Office 365).
- **Public Cloud:** Shared environment (cheap, scalable).
- **Private Cloud:** Dedicated to one organization (secure, $$$).
- **Hybrid Cloud:** Combo of both.

### **6. Address Translation (NAT & PAT)**

- **NAT (Network Address Translation):** Private IPs converted to public IPs.
- **PAT (Port Address Translation):** Many devices share one public IP using different ports.

Think: NAT = translating addresses; PAT = also tagging them with port numbers.

### **8. Physical Installation Considerations**

- **Rack Units (U):** 1U = 1.75 inches; standard for mounting gear.
- **Power:** Redundant power supplies, UPS, surge protectors.
- **Cooling:** Avoid heat — use HVAC, airflow planning, hot/cold aisles.
- **Cable Management:** Label everything! Velcro, not zip ties!

### **10. Network Monitoring Solutions**

- **SNMP:** Talks to network devices for status info.
- **SIEM (Security Info & Event Mgmt):** Security + log collection in one.
- **NetFlow/sFlow:** Analyzes traffic flow patterns.
- **Syslog:** Collects logs from devices.

### **12. Remote Connection Methods**

- **VPN:** Encrypted tunnel to access network remotely.
- **RDP (Remote Desktop):** GUI access to remote machine.
- **SSH:** Secure command-line access.
- **Telnet:** Like SSH, but insecure (avoid it).
- **VNC:** GUI remote access; open-source RDP alternative.

### **14. Common Data Security Methods**

- **Encryption:** Scrambles data (at rest or in transit).
- **Access Control:** Who can access what.
- **Backups:** Regular and secure — air-gapped or cloud.
- **Firewalls/Antivirus:** Protection from malware and threats.
