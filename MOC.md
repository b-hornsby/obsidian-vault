**Daily (5 min):**

- Check [[nodes/projects/job-search.md|Job Search]] for active applications
- Review [[insights/queries/recent|Recent]] for latest activity

**Weekly — Sunday Review (15 min):**
- Read the latest report in [[weekly-reports-index|Weekly Reports]]
- Review [[insights/queries/unresolved|Unresolved]] for abandoned threads
