## Hermes OBS launch shortcut

On Windows / native Hermes Desktop, launching OBS like `/c/Program Files/obs-studio/bin/64bit/obs64.exe` from the git-bash shell is unreliable. The working method is the Start Menu shortcut:

`C:\ProgramData\Microsoft\Windows\Start Menu\Programs\OBS Studio.lnk`

Usage:

```bash
start "" "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\OBS Studio.lnk"
```

Use this instead of the raw exe path.
