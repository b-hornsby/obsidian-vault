# Coding

*533 conversations about code I couldn't write without AI, projects I wanted to exist, and the slow process of learning by doing.*

---

## The honest truth

I'm not a developer. I'm a "vibe coder" — someone who uses AI tools to write code I couldn't write myself, to build things I want to exist. I've been "learning Python" for over 15 months and I still ask about dictionaries vs lists, basic syntax, and indentation.

But I can direct AI to write code effectively. I can describe what I want to build and iterate with AI tools to produce working code. I understand system architecture at a high level — APIs, databases, containers, front-end vs. back-end — even if I can't implement them from scratch.

That's the gap. And I'm working on it.

---

## The journey

### Python fundamentals
I've asked about Python more times than I can count. I've debugged `ModuleNotFoundError` exceptions, fought with virtual environments, and learned that you should paste the full traceback when asking for help. I've asked a coding professional with 7+ years of experience to help me debug issues.

I've set up text generation web UIs, fought with `requirements.txt` files, and learned that `llama-cpp-binaries` markers might not match your environment. I've asked: *"if I paste my python code can you help me debug this issue?"*

### The Flappy Bird project
I built a Flappy Bird clone as a YouTube series — "Can I Prompt a Flappy Bird Clone in 30 Mins?" I used HTML5 Canvas and JavaScript, and I insisted on proper frame-rate independent physics using delta time calculations. I wanted the impulse-to-gravity ratio to feel authentic — not pixel-per-frame values.

I didn't want it to change anything about the way the game looked. I just wanted the physics to feel right.

### Discord bots
I've set up Discord bots and asked about server permissions: *"what permissions do I need to change in my discord server to allow the bot that I have set up to be the only one posting in that channel?"* I've built community messages and tool guides for Discord servers.

### Multi-agent systems
I've worked on a CrewAI-based multi-agent helpdesk system. I have the knowledge base in the project, I've defined the five-agent structure, and I've worked through the JSON context profile. I asked: *"trying this again for the 3rd time but I'm working on a multi agent workflow project and I want to utilize crewai to do it."*

### IDE configuration
I've used Cursor as my IDE and fought with the Continue.dev extension. I've asked about Qwen2.5-Coder-32B-Instruct performance on my i7-12700K and why my model took forever for a simple response to "hi."

## What I've learned

**I learn by doing, not studying.** I don't take courses. I pick a project, start building with AI assistance, and learn concepts as I need them. This gives me practical, uneven knowledge — I might understand API integration and Docker deployment but struggle with basic syntax.

**AI is a force multiplier, not a replacement.** I can direct AI to write code and understand system architecture at a high level. But the knowledge doesn't transfer. I'm using LLMs to write Python instead of learning Python.

**Debugging is a skill.** I've learned to isolate problems, research causes, test fixes, and document results. This troubleshooting methodology translates directly to IT support work.

**The 3070 question keeps coming back.** I've asked whether my RTX 3070 can handle coding models. The answer is always: yes, for code generation tasks, a quantized 7B-13B model is fine. Stop worrying and start building.
